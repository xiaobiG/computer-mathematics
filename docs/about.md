# 项目状态

《计算机数学》是一个 Markdown 优先的长期知识库：从计算问题出发，连接定义、推导、代码实验和工程边界。

## 当前规模

| 内容 | 当前状态 |
| --- | --- |
| 主专题 | 5 条：离散数学、线性代数、概率论、数值计算、数论与密码学 |
| 课程正文 | 58 篇，均通过正文结构校验；53 篇实际课程均带层级、前置、时长与实验标记 |
| 综合项目 | 6 个可运行的最小实现 |
| 学习组织 | 学习路线、四层课程架构、成熟度看板、12 周计划、术语表与写作规范 |

## 可运行项目

- [算法可视化实验室](/projects/algorithm-lab)：BFS 队列轨迹、拓扑排序、3-SAT 验证器与全源最短路；
- [最小文本相似度检索器](/projects/text-similarity)：词频向量与余弦相似度；
- [浮点数错误博物馆](/projects/floating-point-museum)：舍入、累计误差、消去误差与蒙特卡洛抽样波动；
- [密码学玩具箱](/projects/crypto-toybox)：快速幂、模逆元、教学 RSA 与椭圆曲线点群。
- [线性代数实验室](/projects/linear-algebra-lab)：矩阵乘法、选主元消元、投影与低秩压缩。
- [朴素贝叶斯垃圾邮件分类器](/projects/naive-bayes-spam)：拉普拉斯平滑、稳定后验、分类与校准评估。

## 发布标准

每次发布前会自动执行：

1. 课程正文结构校验；
2. 全部项目单元测试；
3. VitePress 构建。

具体流程见 [编辑与发布流程](/editorial-workflow)。密码学和数值计算内容始终标注适用范围，教学示例不被视为生产实现。

## 更新方向

下一阶段将深化图论、统计推断、优化与现代密码工程，并将课程文章持续沉淀为可运行的小型实验。每个专题的深度覆盖范围与下一关键缺口见[课程成熟度看板](/course-maturity)。
