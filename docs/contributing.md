# 写作规范

## 每篇文章的最小结构

快速导读可采用以下最小结构；专题核心文章必须采用 [深度文章模板](/templates/deep-lesson)，并完成其中的发布前自检。

```md
---
title: 概念名称
description: 它解决的计算问题。
---

# 概念名称

## 先问一个问题
## 直觉
## 定义与推导
## 代码实验
## 工程边界
## 常见误区
## 练习
```

## 发布检查

- 公式中的每个符号均在首次出现处说明。
- 推导没有跳过决定性步骤。
- 示例代码可运行，且与公式对应。
- 至少包含一个误区、反例或失败案例。
- 说明概念与其他专题的连接。
- 对核心文章，写出手算例子、正确性或复杂度说明，以及带验收条件的分层练习。
