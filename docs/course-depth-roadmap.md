# 课程深度升级路线图

课程数量不是深度。这个站点下一阶段以“读者能独立推导、运行、反驳并迁移”为完成定义，而不是用新增页面数量衡量进展。

## 深度验收标准

每一门被列为主线核心的课程，升级时依次检查：

1. **问题**：是否从真实计算任务或常见错误进入，而非直接罗列公式；
2. **推导**：是否给出关键等式、算法不变量或证明的中间步骤；
3. **反例**：是否明确前提失效时会发生什么；
4. **实验**：是否有可运行、小规模、可重放的代码或报告；
5. **证据**：是否能用测试、证书或独立重算拒绝被篡改结论；
6. **迁移**：是否说明何时应换算法、换模型或交给成熟库。

缺少其中任一项不代表课程无用，但不应把它标为深度正文。

## 优先级

| 优先级 | 课程链 | 首要问题 | 升级成果 |
| --- | --- | --- | --- |
| P0 | 向量→矩阵→最小二乘；图→BFS→Dijkstra；概率→期望→贝叶斯；浮点→误差→稳定性；模运算→RSA→签名 | 是否存在跳步、未声明前提或未解释算法选择 | 完整推导、一个反例、一个可复跑验证 |
| P1 | PCA/SVD、动态规划、假设检验、数值积分、DH/哈希 | 是否把重要诊断误写成保证 | 指标解释、失败路径与工程边界 |
| P2 | 图像质量、子群体监控、随机化算法、透明日志 | 是否把教学小样本外推为生产结论 | 输入合同、重放证书、政策边界 |

P0 课程优先于任何全新主题；只有发现核心链确有断点，才新增页面。

## 四轮升级法

### 1. 证据审计

对候选文章逐项标记六条验收标准，并阅读其配套实现与测试。不要根据篇幅、标题或公式数量猜测深度。先修复事实错误、未完成推导和断链链接。

### 2. 最小可验证增量

一次改动只补一个清晰缺口：例如补齐 BFS 的最短性反证、给重要性采样增加权重诊断，或为关系闭包保留逐层不变量。变更必须同时更新文章、实验/测试（如适用）、路线入口和版本记录。

### 3. 学习链复核

检查前置课是否真的提供术语，后续课是否实际使用它。典型断链包括：把数组坐标突然当作矩阵索引、把“可达”突然当作最短路、把点估计突然升级成行动决策。

### 4. 发布门禁

每次可发布增量运行：

```bash
npm run content:check
npm run projects:test
npm run build
```

发布后确认 GitHub Pages 工作流成功。站点发布使用完整源树快照，确保工作流、依赖锁文件与构建脚本不会因仅上传增量文件而丢失。

## 已建立的示范链

- 图算法：BFS 的路径/队列证书、Dijkstra 与 Bellman–Ford 的适用边界、同图比较与更新失效；
- 概率监控：冻结窗口、分组校准、bootstrap 区间及“无自动行动”合同；
- 数值随机性：二维网格、蒙特卡洛标准误、重要性权重与 ESS；
- 密码协议：身份绑定、撤销、防回滚与透明日志，不实现不安全的真实密码方案；
- 预备知识：集合/数组、张量形状、关系矩阵与可达闭包，连接图算法的表示语义。

## 元复盘：v2.7–v2.9 的深化结果

最近三个版本没有按文章数量推进，而是分别补了三类容易被误读的结论：高斯消元/最小二乘把“返回一个解”分解为行变换等价、驻点条件与病态系数边界；图更新把“旧报告失效”分解为插入时可下降修复和删除时必须寻找替代路径；概率重采样把“有区间”分解为观测级单位与预定义时间块的不同假设。

复盘后的维护规则是：凡是承担这种主线边界的新增深度课，都应立即加入 `priorityDeepLessons` 门禁，持续检查问题、定义、推导、边界和实验五个可见阶段。下一轮先审计现有课程的证据是否被此门禁覆盖；只有出现无法由深化解决的学习链断点，才增加新主题。

## 当前不做什么

- 不因“下一关键缺口”而机械扩展相邻专题；
- 不把一次固定种子、单个指标或小规模证书包装成生产保证；
- 不为教学目的实现真实密钥、证书、更新器或攻击代码；
- 不进行与学习链无关的站点视觉重构。

## v3.0 起步：将“生成时证书”升级为外部可重放证据

v2.9 的报告审计证明了一个维护原则：报告中写着 `valid: true` 不能单独构成证据；读者、测试和后续课程需要一个只依赖声明输入与报告的重放入口。v3.0 不把这一原则机械套到所有页面，而是优先审计 P0/P1 主线中仍只有生成时布尔标记的实验。

首个增量是 [特征值与 PCA](/linear-algebra/eigenvalues-pca)：`pca_2d_report_certificate` 从二维输入独立重算中心化、协方差、主方向、投影、重构误差和证书字段，并拒绝被篡改的误差或 `valid` 标记。该页现在纳入 `priorityDeepLessons` 门禁。

同一轮 SVD 审计还纳入了“公式本身也是学习证据”的检查：低秩图像压缩与低秩推荐中的截断分解和 ALS 正则化公式已修正；内容门禁会拒绝已发现的缺反斜杠 `qquad` 与错误粘连 `\\sum_up_`。这不是通用 TeX 解析器，不能替代渲染检查；它只把真实发生过、会改变读者所见公式的错误变成回归测试。

为避免只检查几个历史拼写模式，v3.0-c 还会对所有正文中的行内/块级数学公式执行 KaTeX 严格解析。它排除代码示例与行内代码，并报告页面和行号；对无法闭合的定界符或 KaTeX 语法错误直接阻止构建。这个检查只保证“渲染器能理解表达式”，不判断公式推导是否正确，也不代替浏览器中的版式审查。

随机 SVD 审计说明“重放”也必须检查结构：逐项 `zip` 比较若不先核对长度，可能只验证一份被截断矩阵的共同前缀。v3.0-d 将完整近似矩阵形状纳入随机 SVD 报告证书，并以缺行、缺列的篡改测试固定这一边界。后续对报告型实验要先检查是否存在同类前缀比较漏洞，再考虑新增指标。

v5.5-a 再检查这条链的课程边界：随机 SVD 虽然曾内部生成范围发现，却无法接收读者已经运行、保存并验证的范围报告；下游会悄悄重新采样，读者无法证明它实际分解了哪一个子空间。现在 `randomized_svd_from_range_report` 仅消费可重放的 `RandomizedRangeReport`，保存其为 `source_range_report`，并拒绝矩阵、基、seed、过采样或幂迭代不一致的来源。范围发现不再退化为一段文字或一个 seed；下游的实际分解空间成为可检查的输入。这个教学实现仍不提供高概率误差界、稀疏/分布式算法或生产级稳定 QR。

v5.6-a 将这份可验证重构继续交给[图像误差指标](/linear-algebra/image-error-metrics)。此前读者必须手工抽取 `approximation`，质量报告无法追溯它是否来自同一随机范围、随机 SVD 与参考图。`randomized_svd_image_quality_review` 现在只消费可重放的随机 SVD 产物，再用其中的实际重构计算 MSE、RMSE、PSNR 和最大误差，并将读者声明的 MSE 预算变为 `within_mse_budget` 或 `exceeds_mse_budget`。这条数值结论固定 `automatic_action="none"`：预算不能取代视觉、文件编码、检索、分类或部署决策。

v5.7-a 审计概率链时发现，[概率再校准](/probability-ml/recalibration)虽已拟合 Platt scaling，[生成模型与逻辑回归](/probability-ml/generative-discriminative-logistic)的成本敏感决策却只接收裸概率；读者无法证明输入 `.75` 来自何处。现在 `platt_calibration_report` 保存验证集、超参数、拟合参数、轨迹和前后损失；`calibrated_cost_sensitive_decision` 只消费可重放的上游产物，再以声明成本计算期望损失。同一原始 `.9` 在 $c_{FP}=4,c_{FN}=1$ 下可从裸分数的判正变成验证集校准后约 `.75` 的判负。结论仍固定 `automatic_action="none"`：这不是在线校准、成本估计、因果保证或高风险自动决策。

## v3.1：相关观测的真实抽样单位

时间块 bootstrap 已说明相邻事件不能逐条重抽，但“同一用户或设备多次出现”是不同的相关结构。v3.1-a 新增[簇级 Bootstrap](/probability-ml/cluster-bootstrap-calibration)：预定义、标识唯一的完整用户/设备簇成为抽样单位；报告绑定簇大小、政策、种子和区间，并明确 `automatic_action: none`。该课纳入优先深度门禁。

下一步不机械组合时间块和簇级采样。先审计是否存在明确的同时相关场景、配对窗口定义和最小有效簇数；缺少这些前提时，应解释边界并转向经过领域审查的设计，而不是声称一个通用 bootstrap 合同。

### v3.1-b：渲染器定界符一致性

渲染器审计确认当前 `markdown-it-katex` 只接受 `$...$` 和 `$$...$$`；7 篇课程遗留的 `\\(...\\)`、`\\[...\\]` 会被当作普通文本。已统一转换为受支持的定界符，并让 KaTeX 门禁拒绝旧写法。这个增量修复的是“正确公式没有被渲染”的交付问题，不声称校验了公式的数学正确性或所有屏幕尺寸的版式。

为验证的不是源码假设而是真实产物，v3.1-c 在 VitePress 构建后扫描 HTML：拒绝 `katex-error` 节点与正文中遗留的旧定界符，同时跳过代码示例和脚本。它补足“公式可解析”与“公式被渲染到静态页面”之间的断层；仍不替代浏览器截图、无障碍或移动版式检查。

## v3.2：从统计量到可审计的随机实验

假设检验课已解释零假设、尾部概率、可交换性和业务边界，但固定种子置换结果原先没有独立重放入口。v3.2-a 将统计量、极端次数、加一修正 p 值、轮数和种子绑定到 `permutation_test_certificate`，并把[假设检验与 p 值](/probability-ml/hypothesis-testing)加入优先深度门禁。

这项证书只证明报告忠实运行了声明的 Monte-Carlo 算法；不把伪随机可复现性混同于可交换性、独立性、零假设概率或预注册。下一轮先审计 P1 数值积分和 DH/哈希主线是否存在类似“输出可算但前提未被可见化”的断点。

### v3.2-b：密码记录的 fail-closed 合同

审计数值积分与 DH 后，二者已有足够的过程轨迹、前提和重放检查，故没有为了版本对称性修改。密码存储课则有一个具体缺口：示例称记录为自描述数据，却没有验证派生值的类型与长度。现在 `verify_password` 在派生或比较前拒绝算法、轮数、盐和 32 字节派生值不符合合同的记录；这让损坏存储数据与普通密码不匹配保持不同的处理路径。课程加入优先深度门禁，并明确该拒绝不替代恢复、审计或认证平台的事件响应。

## v3.3：从单个信任锚到可审计的根轮换治理

身份生命周期、防回滚和透明日志三课已经分别讲清“谁的密钥”“哪个版本”和“历史是否被改写”，却还没有给出它们共同面对的过渡问题：根集合改变时，旧规则如何约束新规则。v3.3 新增[信任根轮换与阈值监督](/number-theory-crypto/trust-root-rotation)：当前根集合的阈值授权、单调纪元和监督证据成为同一份虚构报告的可重放条件；任何结果都保留 `automatic_apply: false` 与 `cryptographic_verification: not_performed`。

这不是多签、密钥管理或更新器的实现。下一轮不自动扩展根轮换的细节，而是审计其他专题中是否还存在“单一输出掩盖不同前提和决策权”的主线断点。

### v3.3-b：重要性权重的数值表示与统计前提

重要性采样课原先已说明 ESS 不等于误差界，却把“高维应使用对数域”停留在一句边界提示。现在实验新增 `log-weight-diagnostics/v1`：以 max-shift 和 log-sum-exp 稳定重建归一化权重、ESS 与最大权重，并拒绝非有限输入或篡改报告。课程把它与无界/奇异积分、支撑遗漏和事后自适应提议明确分离：稳定计算有限权重不证明目标可积、方差有限或提议有效。该课纳入优先深度门禁。

### v3.3-c：动态最短路的稳定边身份与顺序语义

单边插入/删除课已经说明标签单调性不同，却未把平行边与批量操作的身份/顺序写入合同。现在 `ordered-shortest-path-updates/v1` 以稳定 `edge_id` 区分平行边，逐项应用插入、删除或改权，并在每个快照完整重放 Dijkstra。它是语义与正确性 oracle，不是高效动态最短路实现；替换路径、并发快照和摊还复杂度仍需单独设计。

### v3.4-a：关系、布尔矩阵与稀疏查询桥接

Meta Review 发现基础链已完整，但“关系复合”到“图表示选择”仍缺少可运行桥梁。`boolean-relation-composition/v1` 让布尔矩阵乘积与邻接表两跳扫描在同一关系上重放并比较操作计数；课程明确区分布尔、路径计数与 min-plus 代数，不将当前快照计数外推成性能保证。

接下来的审计顺序是：先检查 SVD/PCA 到低秩近似这一链上“页面解释的量”是否都有独立验证，再检查离散、概率、数值和密码学各一条 P0 主线的同类缺口。已有可重放证据的页面不为追求对称性重复修改；新主题仅在前置链确实断裂时才加入。

## v3.5：核心课程的可审计反例

贝叶斯课原本已推导赔率相加，并在文字中警告条件相关会重复计数；但读者仍无法用同一组数字比较“独立模型”与“联合模型”的结论。v3.5-a 新增 `correlated-evidence-comparison/v1`：它保存两条边缘似然、独立连乘产生的联合似然、显式给出的联合似然、两条后验及差值。完全重复的探测器例子把错误的独立后验 $0.64$ 与正确联合模型的约 $0.308$ 放在同一份可重放报告中。

这不是从样本自动发现相关结构的算法，也不把统计相关解释为因果；它只要求读者在使用朴素贝叶斯的加法规则前，明确哪一份联合概率模型支撑该规则。后续深度化仍遵循同一准则：优先将会实质改变答案的关键假设，变成可修改输入、可观察输出和可拒绝篡改的教学实验。

### v3.5-b：子群体报告的声明组宇宙

子群体课此前以最低样本量拒绝小组结论，却仍从本窗口已经出现的标签生成组列表；这与“预先定义的组”不一致，也让零样本组的覆盖缺口不可见。现在 `subgroup-monitoring/v1` 要求 `declared_groups`：报告按其冻结顺序输出每一个组，未出现的组保留 `count=0`、`metrics=None` 与证据不足解释；所有实际观测组必须属于这份声明，证书同时绑定门槛和组宇宙。

该合同不允许任意敏感属性进入审计，也不补偿事后搜索、多重比较、标签偏差或因果问题。它只让这些前提中的一个——“究竟审计哪些组”——在输入、输出和篡改拒绝中可见。

### v3.5-c：从自报可信到冻结身份登记

发布策略课已有版本、防回滚、用途和撤销检查，但候选包原先仍能通过 `key_identity_trusted`、`key_status` 字段自报关键事实。这和公钥生命周期课的身份绑定原则矛盾。`signed-release-policy-audit/v2` 现要求一个冻结的 `trusted-key-registry/v1` 教学输入，以 `(issuer,key_id)` 匹配候选并核对算法、用途与状态；候选声明自身可信不再是可接受的模型。

该登记表不建立现实身份、不验签、不下载撤销信息，也不能代替根轮换或透明日志。它的教学增量在于将“可信绑定先于验签”的顺序变成可改变输入、可观察拒绝理由和可重放证书。

## v3.6：核心链的系统深度化

Meta Review 后，项目不再优先为已有完整主线叠加相似的元数据合同，而是从尚未进入优先深度门禁的核心文章中选择真正的实验断点。v3.6-a 升级[矩阵的四个基本子空间](/linear-algebra/four-fundamental-subspaces)：`fundamental-subspaces/v1` 从 $A$ 与 $A^T$ 的 RREF 同时构造列空间、行空间、零空间与左零空间的基，并验证两条秩—零度恒等式以及两组正交补。

它仍明确受限于容差和小规模 RREF，不把课堂中的“零”伪装为生产数值的有效秩结论。该阶段之后，每个候选升级都须先证明存在同样实质的断点：原课程是否缺少能让读者改变前提、观察不同结果并重放检查的完整路径。

### v3.6-b：递归树工作量的逐层重放

[递推关系与分治复杂度](/discrete-math/recurrences)已能展示归并树层级，却只能由读者手动把“每层为 $n$”和“总量为 $n\log_2 n$”拼回结论。v3.6-b 增加 `merge-sort-recursion-tree/v1`：固定二的幂输入后，报告保存每层的深度、子问题数、子问题规模和合并元素量；证书从输入重新生成并逐字段比对层连续性、分割守恒和总工作。

它不测墙钟时间，也不把元素比较次数与按元素计的合并工作混为一谈；不规则规模的渐近分析仍须回到递归树或代入法。该增量的价值是让学习者能改变规模、查看完整层证据，并看到任意一层或总量被改写时如何被拒绝。

### v3.6-c：时间分层的簇级不确定性

时间块与簇级 bootstrap 分别保留了短期时间结构和用户/设备相关，但把其中任一合同用于“两者同时存在”的数据，都会静默破坏另一个轴。v3.6-c 新增[时间分层簇级 Bootstrap](/probability-ml/time-stratified-cluster-bootstrap)与 `time-stratified-cluster-calibration-bootstrap/v1`：报告冻结时间层，在每层内整簇重采样，并保存时间层、簇 ID、簇大小、种子与 ECE 差区间；证书完整重建这些量。

它要求簇不跨时间层，刻意拒绝纵向重复用户，而不是把不成立的独立性包装为“更高级 bootstrap”。这给出一个可观察的中间模型：保留已声明的趋势位置和簇内观测，同时明确把配对纵向设计、趋势模型和因果分析留在合同之外。

## v3.7：从布尔结论到可定位反例

v3.6 的 Meta Review 发现多门核心课已有完整推导和实验，不应为持续迭代而重复改造。剩余的真实断点出现在[集合、关系、等价类与偏序](/discrete-math/sets-relations-orders)：原验证器只回答性质真/假，读者无法知道哪一对或哪条关系链违反定义。v3.7-a 增加 `finite-relation-diagnostic/v1`：报告在自反、对称、反对称或传递失败时保存一个具体反例，证书重放结论和见证。

这不是通用定理证明器，也不声称报告顺序给出数学上唯一或最小的反例；它只让有限关系中失败的量词可定位。后续版本继续优先寻找这种“答案变为可解释诊断”的缺口，而不是为了形式对所有布尔报告追加相同字段。

### v3.7-b：端点奇性的截断极限

[数值积分](/numerical-computing/numerical-integration)此前正确拒绝非有限函数值，却没有让读者区分“端点不能采样”与“不当积分发散”。v3.7-b 增加 `endpoint-power-improper-integral/v1`：对 $\int_0^1x^{-p}\,dx$ 保存递减截断下的精确积分，并在 $p<1$ 时重放极限和遗漏尾项；$p\ge1$ 则明确报告发散而非一个伪精度数。

该实验是有解析积分的幂函数族，不会从有限采样点判断任意黑盒奇性或无界域的可积性。它的教学价值在于把“求积器报非有限”后的下一步推理变成可运行、可篡改检测的边界案例。

## v3.8：从归约方向到双向构造

[P、NP 与归约](/discrete-math/p-np-reductions)原先讲清了 $A\le_pB$ 的方向，却没有让读者实际构造一对 yes/no 等价的实例。v3.8-a 增加 `independent-set-to-cnf-sat/v1`：用选择槽位把独立集判定编码为一般 CNF-SAT，有限报告同时重放构造公式、SAT 赋值解码与小图独立集 oracle。

它刻意不把一般 CNF 说成 3-CNF，也不以有限枚举“证明” NP 完全性；长子句到三文字的 gadget、归约的普遍证明和大实例求解仍是后续理论工作。教学增量是将归约所需的双向等价变成可检查的具体构造。

### v3.8-b：裸签名的可乘反例

[数字签名](/number-theory-crypto/digital-signatures)曾说明裸 RSA 有乘法结构，却没有让读者实际看到两份有效签名如何组合成另一份有效代表元签名。v3.8-b 增加 `raw-rsa-signature-multiplicativity/v1`：它仅用小参数代表元重放 $s_1s_2$ 验证为 $m_1m_2\bmod n$ 的等式，并让课程解释为什么标准消息编码、域分离和安全证明不能省略。

它不是签名伪造工具、填充实现或生产 API；真实签名始终交给成熟库。该增量只将已经存在的代数风险变成可观察、可篡改检测的教学反例。

## v3.8 Meta Review：从“可重放”转向“可迁移”

本阶段已经建立了 110 篇课程正文、29 篇优先深度课门禁、全项目测试、公式源文件/渲染产物检查和公开发布流程。v3.6–v3.8 的七个增量解决了不同的真实断点：四子空间、递归树、双轴重采样、关系反例、端点奇性、归约构造和裸签名可乘性。它们的共同价值是把容易被误读的结论绑定到明确前提和可观察反例。

同时，这些版本也暴露出方法风险：若继续把“新增报告/证书”当作默认答案，项目会在形式上越来越可审计，却未必让读者更能独立建模、选方法或修复错误。因此 v4 的验收重心改为**可迁移**：每个候选改动必须先证明它至少补齐下列一项，而不能只给现有输出增加元数据。

1. **错误路径**：提供一个貌似合理却会失败的模型、证明或实现，并要求读者定位失败前提；
2. **跨课迁移**：让前置概念实际进入后续算法/模型，避免只在“下一步”链接中出现；
3. **决策权衡**：用相同输入比较两种可行方法的成本、误差、假设或结果，而不是只展示一个正确算法；
4. **读者行动**：增加能改变输入、预测输出、运行并解释差异的练习或小实验。

下一阶段先对五条专题主线各挑一处“读者完成前置课后仍不能做出下一步选择”的断点进行证据审计；只有审计确认缺口，才形成 v4 版本。已有重放合同只在发现实际覆盖错误时修复，不为对称性继续扩张。

## 如何贡献

从[课程成熟度看板](/course-maturity)选择一个主线，按本页六条标准写出缺口和可验证证据，再创建最小增量。每一轮在[版本迭代看板](/version-iteration)记录目标、范围、验证、差异与下一决策。

## v4：从“可重放”到“可做度量决策”

### v4.0-a：余弦相似度与欧氏距离的同集对照

[向量与点积](/linear-algebra/vectors-dot-product)早已解释余弦相似度的尺度不变性，也提醒读者预算等任务需关注绝对量；但这两句说明没有要求读者在相同输入上承担一次选择。`compare_similarity_metrics` 以一个查询和同一候选集同时输出余弦与欧氏排序：完全同向但放大的候选会在余弦下领先，长度接近而方向略偏的候选会在欧氏距离下领先。

这次升级刻意不生成新的“正确排序证书”。它要求读者先陈述总量是否有业务意义、预测两种排序是否分歧，再改动向量运行实验。零向量、维度不一致和重复标签会被拒绝，以免把不可比较的输入伪装成度量选择。该增量同时满足 v4 的“决策权衡”和“读者行动”标准：函数展示计算结果，课程把最终选择保留给任务语义。

### v4.1-a：已校准概率的成本敏感阈值

[生成模型、朴素贝叶斯与逻辑回归](/probability-ml/generative-discriminative-logistic)已经说明 $0.5$ 阈值会丢失概率信息、错误成本需单独报告，却没有把“成本不同”变成同一预测上的实际选择。`cost_sensitive_decision` 以 $p=0.2$ 为共同输入：相同误报/漏报成本时推荐判负，漏判成本为九倍时推荐判正；概率不变，改变的是明确的损失假设。

该模块从两种动作的期望成本推导阈值 $c_{FP}/(c_{FP}+c_{FN})$，并把精确平局返回为未决，避免把任意的 `>=` 约定伪装成数学结论。它只适用于已经在相关人群上校准、且成本由有权责任方预先声明的抽象教学场景；高风险现实动作仍需人工治理、程序性公平审查和领域规则。该增量满足 v4 的“决策权衡”和“读者行动”，且没有增加新的审计报告或证书。

### v4.2-a：数值微分的模板定义域选择

[数值微分与步长选择](/numerical-computing/numerical-differentiation)已经推导中心差分的二阶截断误差，并在边界说明中提到单侧公式，但读者无法把“高阶”与“模板是否可取样”放在同一输入里比较。`finite_difference_stencil_comparison` 对平滑内部点保留中心、前向两个估计；在 $\log x$ 的 $x-h<0$ 情形显式将中心模板标为不可用，而仍显示可计算的前向误差。

它不把“能算”误说成“足够精确”：步长、舍入、噪声、缩放和变量变换仍是后续选择。读者必须先预测哪些模板点在定义域内，再调整位置与步长并解释为何中心模板有时因几何/定义域前提而失效。这满足 v4 的“错误路径、决策权衡与读者行动”，且不增加新的证书。

### v4.3-a：DH 密钥确认与身份认证的分界

[Diffie–Hellman 密钥交换](/number-theory-crypto/diffie-hellman)已有诚实和中间人两份转录，却将“密钥确认”留在术语表和后续阅读中。`key_confirmation_comparison` 把两份转录并列：诚实端点确认一条共同会话；中间人替换时，Alice 和 Bob 也各自确认与 Mallory 的会话，但二者没有共同会话，更没有已绑定身份。

这个小模型刻意不实现 MAC、KDF、签名或证书，也不构成协议。它只让读者区分两个看似接近的断言：“当前对端知道同一会话元素”与“当前对端是预期身份”。要把前者提升为后者，仍必须由成熟协议把临时公钥、身份凭据、转录和上下文安全绑定。该增量满足 v4 的错误路径、跨课迁移与读者行动标准。

## v4 Meta Review：从固定对照到读者构造

v4.0–v4.3 已在四条专题主线上形成明确增量：同一候选在余弦/欧氏度量下排序分歧；同一校准概率因错误成本改变动作；同一步长因定义域改变可用差分模板；同一 DH 代数关系区分密钥确认与身份认证。四次升级都让原先只以文字出现的前提进入可改动输入与可观察输出，且没有继续叠加证书。

但它们也有共同形式：课程提供一个精心设计的固定对照，读者主要负责预测和解释。因此下一阶段不再以“第五门专题也需要一个双路径函数”为目标。v5 的候选必须优先补齐更强的自主能力：读者从题意构造反例或输入合同、把前置课产物迁移进下一课、定位失败轨迹中的第一处前提破坏，或定义使两个方案可比较的外部评价标准。

当前基线是 110 篇课程正文、105 篇实际课程、29 篇优先深度文章门禁、420 项项目测试，以及数学源文件/渲染产物双层检查。下一轮先审计“给定答案对照”之后读者仍无法独立完成的任务；若没有具体证据，保留站点现状而不制造 v5 编号。

## v5：从给定对照到读者构造

### v5.0-a：投影—最小二乘的建模诊断

[最小二乘](/linear-algebra/least-squares)先前能让读者比较固定 $A,b$ 的正规方程与 QR，却没有要求读者从任务语义决定每一行/列及验收不变量。`diagnose_least_squares_case` 接收读者构造的设计矩阵和目标，明确区分：$b$ 在列空间中时验收 $Ax=b$；满列秩但 $b$ 不可达时保留非零残差并验收 $A^Tr\approx0$；秩亏或欠定时停止并要求声明最小范数、稀疏性或其他解选择规则。

这不是一台自动建模器，也不替代 rank-revealing QR/SVD。它的价值是把“投影”从固定公式迁移到建模动作：读者必须先给每行观测、每列特征和目标向量以含义，再依据诊断选择可被检查的数学不变量。该增量满足 v5 的自行构造、跨课传递和失败前提定位标准。

### v5.1-a：贪心—DP 的任务合同与目标诊断

[贪心算法](/discrete-math/greedy-exchange-arguments)和[动态规划](/discrete-math/dynamic-programming-dag)原先分别给出了固定的无权与加权活动表，读者可以重放扫描、DP 与穷举，却仍可能从“出现区间”这一表面特征反推算法。`diagnose_activity_task` 现在要求读者明确半开区间语义、`maximize_count` 或 `maximize_value` 目标、与目标一致的验收不变量及活动字段；随后才返回最早结束贪心的 `current_end`，或前缀 DAG DP 的 $OPT(j)$。

同一组时间窗在价值目标下会显示最早结束得到的值与 DP 的最优值，并把最先失效的证明前提定位为“交换必须保持声明的总价值”；即使某个具体输入刚好打平，这个前提也没有恢复。小于等于 18 项时结果用穷举核对，大输入则明确不假装有指数 oracle。该增量不是自然语言排程器、生产调度器或多资源优化器；它只把“目标改变，定理与状态也必须改变”变成读者可构造、可运行、可验收的数学动作。

### v5.2-a：求根的保证等级合同

[牛顿法](/numerical-computing/newton-method)和[割线法](/numerical-computing/secant-method)先前已有停止条件、轨迹和失败边界，但读者仍从函数名开始调用。`diagnose_root_task` 现在要求读者声明：任务需要“有限残差并始终保留符号变号区间”，还是“无导数条件下的局部残差”；还要声明导数可用性、初始点、容差与迭代预算。前者选择受保护 Newton 并报告二分回退，后者选择割线并拒绝把局部成功升级为全局保证。

该诊断会指出两种方法各自不能自动证明的第一条前提：受保护方法的符号变化仍依赖模型连续性；割线不保留符号区间，故不能证实根始终被包含。它不是函数表达式解析器、Brent 实现、多维求根器或生产停止策略；价值在于让读者为所需保证选择输入合同和验收不变量，而非从一个成功的 $\sqrt2$ 样例反推结论。

## v5.2 Meta Review：从“写合同”到“跨课使用产物”

v5.0–v5.2 已完成三种不同的读者构造：最小二乘把观察翻译为 $A,b$ 并选择残差不变量；排程把目标翻译为贪心或 DP 的状态；求根把所需保证翻译为区间保护或局部残差。它们都避免了固定样例的答案回放，当前站点有 110 篇课程正文、105 篇实际课程、29 篇优先深度文章门禁和 428 项项目测试。

审计概率线的结果说明不能把“合同”当成下一步的万能形状：置信区间课程已经区分抽样单位、覆盖率与非抽样偏差；带标签监控已冻结窗口、指标、阈值与人工复核；观测级、时间块、簇级和时间分层簇级 bootstrap 也已让重采样单位进入输入。为这些内容再次包一层选择函数不会增加读者独立能力。

因此 v5.3 的硬门槛改变为：新产物必须让读者把一个上游课程的结果真正传入下游问题，并在下游改变可验证的结论、可接受的方案或首个失败前提。仅新增字符串合同、固定双路径对比、报告字段或证书，不足以成为版本。优先审计“置信区间/抽样单位 → 业务最小效应与人工复核”或其他存在同等级明确数据流的链；若找不到，不制造版本。

### v5.3-a：均值差区间到最小效应人工复核

[抽样误差、置信区间与覆盖率](/probability-ml/confidence-intervals-sampling)原先正确说明区间、业务最小可接受效果和上线决策不可混同，却未让读者将同一份区间产物带到下一步。`two_sample_mean_interval` 现在从两组有限观测产生明确的 $\bar x_T-\bar x_C$、标准误和正态近似区间；`practical_effect_review` 接收这份完整产物与上下文声明的最小效应，并重新计算上游结果后才输出“整体高于、整体低于或穿过门槛”。

这满足 v5.3 的实际数据流：改变上游观察会改变下游区间，改变下游最小效应会改变可解释的证据状态。任何状态均为 `automatic_action: none`，并把随机分配/抽样、独立分析单位、近似质量、阈值正当性、伤害成本与子群体影响保留给人工复核。该模块不是 A/B 决策器、因果识别器、顺序检验、功效计算器或生产统计库。

### v5.4-a：透明日志追加产物到根轮换复核

[透明日志的 Merkle 证明](/number-theory-crypto/transparency-logs)曾能重放一份追加列表，[信任根轮换](/number-theory-crypto/trust-root-rotation)则只接收 `witness_evidence_available` 布尔值，两门课之间没有实际证据流。`root_rotation_log_link_review` 现在接收两份已验证的上游产物：根轮换策略报告和追加日志报告；它从旧/新根集合导出新增根，检查 `key:<root-id>` 是否真正覆盖在未改写的新日志条目中。

这条连接会改变下游结论：删掉新增根条目得到“缺少日志条目的人工复核”，覆盖完整得到“带策略与追加日志证据的人工复核”，篡改日志则不能进入下游。无论哪一种都固定 `automatic_apply=False`、`cryptographic_verification="not_performed"` 和无身份绑定：日志追加不是批准签名、密钥身份、独立见证或真实根管理系统。
