## 验证口径

1. `npm run content:check`：课程正文结构、元信息、练习数量、答案提示数量、内部链接、路线锚点与专题课程数检查；
2. `npm run projects:test`：所有教学项目的单元测试；
3. `npm run build`：公式、导航、静态站点构建；
4. GitHub Pages：公开页面可访问，数学正文含 KaTeX 输出。
5. 课程路线锚点：内容检查会核对五大专题中每条核心路线均保有对应课程或综合项目页面，避免重命名或删改留下断链。

## 如何使用

- 初学者先沿各专题首页的“课程地图”完成已有深度主线；
- 想进入工程层，优先运行对应项目并完成开放练习；
- 贡献新文章时，复制[深度文章模板](/templates/deep-lesson)，并从本页“下一关键缺口”选择题目。

## 维护原则

不以文章数量作为完成指标。一个专题只有在预备知识、核心概念、推导算法、工程实验四层均形成可阅读路径时，才可称为“深度版完成”。v3.8 Meta Review 后，后续升级还必须证明读者能力的改变：能定位错误路径、跨课迁移概念、比较决策权衡，或主动改变输入并解释输出；不能只为已有结果增加同类报告字段。
