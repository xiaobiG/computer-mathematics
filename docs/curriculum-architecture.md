# 课程架构与深化路线

《计算机数学》不是概念词典。每个专题都沿同一条主线组织：

```text
数学直觉 → 严格定义 → 可推导结论 → 可实现算法 → 可验证实验 → 真实系统迁移
```

## 四层学习模型

| 层级 | 读者目标 | 文章必须回答的问题 | 典型交付 |
| --- | --- | --- | --- |
| 0. 预备知识 | 补齐符号与基础直觉 | 符号、函数、集合或 Python 工具是什么？ | 最小例子与自测 |
| 1. 核心概念 | 建立正确模型 | 定义解决什么问题，哪些直觉会误导？ | 定义、图像、反例 |
| 2. 推导与算法 | 理解为什么这样做 | 结论如何推导，算法为何正确、复杂度多少？ | 推导、伪代码、证明 |
| 3. 工程与前沿 | 迁移到真实系统 | 数值、安全、性能或数据边界是什么？ | 实验、测试、项目任务 |

每篇深度正文在开头标注所属层级、前置知识、预计时间和配套实验；读者可停在第 1 层获得模型，也可沿第 3 层进入代码与工程边界。

共享的第 0 层入口是[计算机数学预备知识](/foundations/)，先将符号、函数与有限求和对齐到 Python 的输入契约和半开区间，再进入任一专题。

## 五大专题路线

### 程序员的线性代数 · v0.2 已完成

向量与基 → 矩阵变换 → 消元与最小二乘 → 特征值/PCA → SVD。下一轮补充四个基本子空间、Gram–Schmidt/QR、LU、幂迭代、Jacobian/Hessian，并以图像压缩与检索系统收束。

### 算法背后的离散数学 · 下一深度专题

命题逻辑与证明方法 → 集合/关系/递推 → 循环不变量与复杂度 → 图论、BFS、DFS、并查集 → 最短路、贪心、动态规划 → P/NP 直觉。配套项目为图算法可视化与正确性测试实验室。

### 机器学习需要的概率论

概率空间与条件概率 → 随机变量与联合分布 → 期望/方差/协方差 → 大数定律与采样 → 贝叶斯、MLE、MAP、交叉熵/KL → 检验、蒙特卡洛与生成模型。配套项目为垃圾邮件朴素贝叶斯分类器与校准评估。

### 数值误差与浮点数

IEEE 754 → 误差传播与条件数 → 稳定性、Kahan 与 pairwise summation → 求根、微分、积分、插值 → 数值线性代数 → 容差、属性测试与可复现性。配套项目为数值错误博物馆。

### 密码学的模运算与数论

整除、贝祖与模逆元 → 快速幂和中国剩余定理 → 素数、有限域与群论直觉 → RSA、Diffie–Hellman → 哈希/MAC/密码存储 → 椭圆曲线预备。配套项目为仅教学用途的密码学工具箱与攻击演示。

## 深度文章发布标准

一篇标记为“深度版”的正文必须具备：

1. 真实编程问题或反例；
2. 学习目标、直觉、严格定义与符号解释；
3. 不跳关键步骤的推导或正确性证明；
4. 可运行的 Python 代码和复杂度说明；
5. 至少一个失败案例、工程边界和四道分层练习；
6. 前置、后续、项目任务与站内链接均可验证。

## 六周专题节拍

| 周次 | 产出 |
| --- | --- |
| 1 | 预备知识与核心概念 |
| 2 | 推导型文章 |
| 3 | 算法、证明与复杂度 |
| 4 | 可运行实验或可视化 |
| 5 | 分层练习、答案提示与误区 |
| 6 | 技术审校、读者体验审校、专题项目发布 |

每季度只完成一个专题的深度版，避免同时扩张造成章节深浅不一。
