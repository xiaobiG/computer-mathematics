# 组合计数、容斥与鸽巢原理：如何不重不漏地数

## 学习目标

完成本课后，你能：

- 区分加法原理、乘法原理与“对象会重叠”时的容斥；
- 推导排列、组合与二项式系数的来源，而不把公式当作查表结果；
- 从有限桶分配证明碰撞必然发生，并给出具体见证；
- 将计数模型用于子集枚举、哈希冲突、状态空间和复杂度估算；
- 指出“数出了多少种”依赖对象是否有序、是否可重复以及是否真的互斥。

## 从一个重复计数的错误开始

某站点有喜欢算法的用户集合 $A$ 和喜欢概率的用户集合 $B$。若直接报告 $\lvert A\rvert+\lvert B\rvert$，同时喜欢两者的人被数了两遍；但如果把“选用户名的第一位”和“第二位”相乘，又是在数两次独立选择。计数的关键不是背公式，而是先回答：每个结果在当前分解中出现几次？

## 定义与计数模型：加法与乘法原理

若方案来自彼此互斥的类别 $C_1,\ldots,C_k$，每个方案恰好属于一个类别，则

$$
\lvert C_1\cup\cdots\cup C_k\rvert=\sum_{i=1}^k\lvert C_i\rvert.
$$

若一个方案是按顺序完成的 $k$ 步，第 $i$ 步在此前选择固定后有 $n_i$ 种可能，则

$$
\text{方案数}=\prod_{i=1}^k n_i.
$$

例如长度为 4 的二进制串每一位有 2 种选择，故有 $2^4=16$ 个；这正是枚举所有子集时的状态数。反过来，若“第 2 步可选项”依赖第 1 步，就不能机械写成固定的 $n_1n_2$，而须按分支求和。

## 排列与组合：为什么要除以阶乘

从 $n$ 个不同元素中依次取 $k$ 个、不重复且顺序重要时，第一位有 $n$ 种，之后依次为 $n-1,\ldots,n-k+1$，所以

$$
P(n,k)=n(n-1)\cdots(n-k+1)=\frac{n!}{(n-k)!}.
$$

若只关心选出的集合，每个含 $k$ 个元素的集合被上述有序过程列出 $k!$ 次，因此

$$
\binom nk=\frac{n!}{k!(n-k)!}.
$$

这里的除法并不是“为了让式子好看”：它来自一个严格的等价类大小——同一无序集合的全部 $k!$ 个排列。也因此当元素有重复时，等价类大小会改变，不能继续套这条公式。

二项式展开给出同一数的另一种解释：在

$$
(x+y)^n=\sum_{k=0}^n\binom nkx^ky^{n-k}
$$

中，得到 $x^ky^{n-k}$ 必须从 $n$ 个括号中选择恰好 $k$ 个取 $x$，故系数就是 $k$ 元子集数。这将组合计数连接到概率论中的二项分布。

## 容斥：交集为何要交替加减

对于两个可能重叠的集合，$A\cap B$ 在 $\lvert A\rvert+\lvert B\rvert$ 中出现两次，故要减回一次：

$$
\lvert A\cup B\rvert=\lvert A\rvert+\lvert B\rvert-\lvert A\cap B\rvert.
$$

三个集合则为

$$
\begin{aligned}
\lvert A\cup B\cup C\rvert={}&\lvert A\rvert+\lvert B\rvert+\lvert C\rvert\\
&-\lvert A\cap B\rvert-\lvert A\cap C\rvert-\lvert B\cap C\rvert\\
&+\lvert A\cap B\cap C\rvert.
\end{aligned}
$$

为什么最后要加回三重交？其中一个元素先被单集数 3 次、两两交集减 3 次，暂时变成 0；加一次才恰好是 1。一般地，属于恰好 $r$ 个集合的元素，在所有非空子集交集中的净系数是

$$
\sum_{j=1}^{r}(-1)^{j+1}\binom rj=1,
$$

这是 $(1-1)^r=0$ 的展开式去掉 $j=0$ 项后的结果。容斥不是“记住正负号”，而是让每个最终对象的系数恢复为 1。

## 可运行实验：把每个交集项公开出来

```python
from projects.algorithm_lab.combinatorics_counting import (
    inclusion_exclusion_certificate,
    inclusion_exclusion_report,
)

universe = ["a", "b", "c", "d", "e"]
sets = {
    "A": ["a", "b", "c"],
    "B": ["b", "c", "d"],
    "C": ["c", "d", "e"],
}
report = inclusion_exclusion_report(universe, sets)
assert report["direct_union"] == ("a", "b", "c", "d", "e")
assert report["direct_union_count"] == 5
assert report["inclusion_exclusion_count"] == 5
assert report["counts_match"]
assert inclusion_exclusion_certificate(universe, sets, report)
```

报告按单集、两两交、三重交逐项保存所选集合、交集成员、符号和带符号贡献；它再与按宇宙直接枚举的并集计数对照。把任意交集项的符号或大小改掉，证书会拒绝。这个实验证明的是给定有限宇宙和显式集合上的算术，不会从样本名单推断总体偏好，也不替代大规模集合上的高效位图或数据库查询计划。

## 鸽巢原理：存在性证明也应给出碰撞

若把 $n$ 个对象放入 $m$ 个桶且 $n>m$，至少一个桶含两个对象；否则每个桶至多一个，总对象数至多 $m$，与 $n>m$ 矛盾。这是鸽巢原理。

它常被误读为“哈希函数不好”。事实上，若输入空间大于固定哈希范围，碰撞由抽屉数量强制发生；好哈希只能改变碰撞分布和攻击难度，不能让有限输出空间变成单射。

```python
from projects.algorithm_lab.combinatorics_counting import (
    pigeonhole_collision_certificate,
    pigeonhole_collision_report,
)

assignments = {"u1": "0", "u2": "1", "u3": "0"}
bins = ["0", "1"]
report = pigeonhole_collision_report(assignments, bins)
assert report["item_count"] == 3
assert report["bin_count"] == 2
assert report["collision_is_forced"]
assert report["collision_witness"] == ("0", ("u1", "u3"))
assert pigeonhole_collision_certificate(assignments, bins, report)
```

调用者必须显式给出全部桶标签，而不能从已经占用的桶倒推桶数。若 3 个对象被映射到 2 个已声明桶，证书必须同时给出共享桶与两个不同对象；若对象数不超过声明桶数，报告会把“碰撞被强制”标为 false，即使某个具体分配恰好发生碰撞，也不会把观察事实混同为定理保证。

## 算法视角：从计数到资源边界

- **子集 DP 与位掩码**：$n$ 个布尔决策产生 $2^n$ 个状态，解释了为何小 $n$ 的精确算法也可能很快失去可行性。
- **哈希表**：鸽巢保证有限桶会有碰撞；链表、开放寻址和负载因子分析讨论的是如何处理，而不是如何消除这一事实。
- **概率模型**：二项分布中的 $\binom nk$ 来自“哪些试验成功”的组合选择，独立性只用于随后给每种排列赋相同概率。
- **约束求解**：容斥可计数满足至少一个条件的候选，但集合数增多时需枚举 $2^k-1$ 个交集项，不能忽略其自身的指数成本。

## 失败案例与工程边界

- **把不互斥事件直接相加。** 同时属于多个集合的对象会重复计数；必须先分区或用容斥。
- **把有序和无序混在一起。** `ab` 与 `ba` 对密码串是不同对象，对二元集合却是同一对象；先定义对象。
- **把“至少一个碰撞”误读为具体桶必碰撞。** 鸽巢只给存在性，具体碰撞取决于分配；报告中的见证来自已给映射。
- **容斥用于很多集合却不计成本。** $k$ 个集合需要最多 $2^k-1$ 个交集，直接计算可能比原问题困难。
- **用有限枚举证明无限命题。** 本课的证书只重放有限标签；一般组合恒等式仍需要代数、双射或归纳证明。

## 常见误区

1. “加法原理总能把类别数量相加。”错误：类别必须互斥，或先改造成互斥分区。
2. “组合数就是排列数少写一个阶乘。”错误：除以 $k!$ 的理由是每个无序集合恰有同样多的有序表示。
3. “容斥只要减掉所有两两交集。”错误：三重交被减了三次，必须再加回。
4. “更多对象进更少桶说明哈希函数实现错误。”错误：这是有限输出空间的必然限制；工程问题是碰撞率、对抗性和处理成本。

## 练习

1. **基础题**：从 8 名同学中选 3 名代表，分别计算“岗位有区分”和“只选代表团”的数量，并解释两者之比。
2. **推导题**：对三个集合中的一个元素分别属于 1、2、3 个集合，逐种计算容斥后的净系数。
3. **编码题**：为 `inclusion_exclusion_report` 构造四个重叠集合，篡改一项交集或符号并确认重放证书拒绝；估算该例会产生多少非空交集项。
4. **建模题**：某服务把 13 个用户 ID 映射到 10 个分片。用鸽巢原理写出能保证什么、不能保证什么；再列出要评估实际负载还需哪些数据。
5. **开放题**：选择一个“至少满足一条规则”的筛选任务，说明你会使用互斥分区、容斥、位图还是近似计数，并解释规模与重叠如何影响选择。

## 练习答案提示

1. 有区分时为 $P(8,3)=8\cdot7\cdot6$；无区分时为 $\binom83$，前者恰是后者的 $3!$ 倍。
2. 单独出现一次时系数为 1；属于两集时 $1+1-1=1$；属于三集时 $3-3+1=1$。
3. 四个集合有 $2^4-1=15$ 个非空交集项；证书会从原宇宙和成员列表重建每项，而不是只比较最终并集大小。
4. 必有至少一对用户落到同一分片；不能断言哪个分片、最大负载或均匀性。还要知道哈希函数、输入分布、桶定义、时间窗口与扩容策略。
5. 明确对象是否可枚举、规则是否重叠、集合数 $k$、可接受的时间/内存和是否允许估计误差；不要因一个小样例可枚举就默认生产数据也可用容斥展开。
