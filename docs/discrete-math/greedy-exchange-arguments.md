# 贪心算法：交换论证与反例构造

## 学习目标

读完后，你能区分“看起来合理的局部规则”与可证明的贪心选择性质；用交换论证证明活动选择的最早结束规则；编写可运行算法并用小规模穷举作测试预言；还能为错误贪心规则构造最小反例。

## 从“每次选最好的”这句危险的话开始

“每次选当前收益最大”听上去高效，却在背包、找零和调度中经常失败。贪心算法不是一种证明方法，而是一种承诺：在尚未知道未来细节时，永久选择一个局部选项。只有证明该选择总能嵌入某个全局最优解时，承诺才安全。

活动选择是经典正例：给定互不必同时进行的活动区间 $[s_i,f_i)$，目标是选最多个不重叠活动。规则是每次选**结束最早**的可选活动，而不是持续时间最短、开始最早或编号最小。

## 严格模型与算法

两个半开区间兼容当且仅当 $f_i\le s_j$ 或 $f_j\le s_i$。先按结束时间排序；维护最近选中活动的结束时间 `current_end`：

```python
def select_activities(activities):
    """Return a maximum-cardinality compatible subset of (start, finish, name)."""
    if any(start > finish for start, finish, _ in activities):
        raise ValueError("活动开始时间不能晚于结束时间")
    chosen = []
    current_end = float("-inf")
    for start, finish, name in sorted(activities, key=lambda item: (item[1], item[0])):
        if start >= current_end:
            chosen.append((start, finish, name))
            current_end = finish
    return chosen

print(select_activities([(0, 3, "A"), (1, 2, "B"), (2, 4, "C"), (3, 5, "D")]))
```

排序成本为 $O(n\log n)$，扫描为 $O(n)$，额外空间不计输出为 $O(1)$。使用半开区间使“一个活动在 2 结束、另一个在 2 开始”可兼容；接口语义必须先定清楚。

## 交换论证：为何最早结束不会损失最优性

令 $g$ 为所有活动中结束最早的一个，令 $O$ 是任一最优解，且 $o$ 是 $O$ 的第一个活动。由于 $g$ 最早结束，$f_g\le f_o$。把 $O$ 中的 $o$ 替换为 $g$：

- $O$ 中其余活动都在 $o$ 结束后才开始；
- 因 $g$ 不晚于 $o$ 结束，它们也都与 $g$ 兼容；
- 替换不改变活动数量。

所以存在一个以 $g$ 开头的最优解。选定 $g$ 后，问题缩小为“从所有开始时间不早于 $f_g$ 的活动中选最多个”；这与原问题同形。对剩余问题重复同一论证，归纳得到算法最优。

这里的关键不是“贪心选得很小”，而是**把任意最优解变成包含贪心选择的最优解**。这就是交换论证的模板。

## 可验证实验：算法与穷举对拍

对很小的输入，枚举所有子集可作为独立预言：过滤兼容集合并取最大基数。随机生成 8 个以内活动，将 `len(select_activities(...))` 与穷举最优值比较。穷举是 $O(2^n n\log n)$，不用于生产，却很适合抓住排序、边界和相等结束时间处理错误。

还应测试性质：输出按结束时间非降；相邻选中活动满足前者结束不晚于后者开始；添加一个与全部活动冲突的活动不会让输出变得不兼容。

## 反例构造：错误规则如何被击败

“选持续时间最短的活动”失败：活动 $A=[0,3)$、$B=[3,6)$、$C=[2,4)$。最短 $C$ 持续 2，只能选一个；按最早结束可选 $A,B$ 共两个。

构造反例的实用步骤是：先找一个诱饵，让错误规则必选它；再在诱饵两侧放置多个可兼容选项；让正确规则能选两侧多个而诱饵阻塞它们。反例不是挑刺，而是发现贪心选择性质缺失的证据。

## 失败案例与工程边界

- **加权活动选择**：若每个活动有不同价值，最早结束不保证总价值最大；需动态规划。
- **区间端点语义**：闭区间 $[a,b]$ 与半开区间 $[a,b)$ 的兼容条件不同，时间系统还要处理时区和精度。
- **在线到达**：活动按时间到达且不能回看时，离线排序算法不可直接使用，竞争分析成为不同问题。
- **目标函数改变**：最大数量、最小空闲、最大权重是不同优化目标，不能复用同一正确性证明。

## 常见误区

1. “贪心正确因为每步都最优。”错误：局部最优并不推出全局最优。
2. “有最优子结构就可以贪心。”错误：动态规划也有最优子结构；还需贪心选择性质。
3. “测试很多随机输入就等于证明。”错误：测试只能找反例，交换论证才覆盖所有输入。
4. “任意排序 tie-break 都无关。”错误：本题同结束时间可任取，但其他问题 tie-break 可能改变可行性或确定性。

## 练习

1. **基础题**：对活动 $[0,2),[1,3),[2,5),[4,6)$ 手工执行最早结束算法。
2. **推导题**：补全交换论证中“替换后其余活动仍兼容”的不等式细节。
3. **编码题**：实现小规模穷举对拍器，随机检验活动选择算法 1,000 次。
4. **开放题**：为“最大收益会议安排”设计状态定义并说明为什么它转为动态规划，而非修补一个贪心规则。

## 练习答案提示

1. 按结束时间排序后依次选择：先选 $[0,2)$，跳过冲突的 $[1,3)$，再选 $[2,5)$；最后比较 $[4,6)$ 是否兼容。
2. 设最优解第一项为 $o$、贪心第一项为 $g$；由 $finish(g)\le finish(o)$ 可知将 $o$ 换为 $g$ 后其余活动仍满足开始时间不早于 $finish(g)$。
3. 随机生成半开区间并固定种子以便复现；穷举过滤两两兼容子集，比较的是选择数量而非活动名称或排序细节。
4. 加权时状态通常是按结束时间排序的前缀，转移为 $OPT(j)=\max(OPT(j-1),w_j+OPT(p(j)))$；局部最早结束不再控制总收益。
