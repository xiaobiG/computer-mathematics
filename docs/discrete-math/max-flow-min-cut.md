# 最大流最小割：残量网络为何能证明最优

## 学习目标

读完后，你能定义可行流、残量网络与割；解释反向残量边为何必要；实现 BFS 选增广路的 Edmonds–Karp；并用“流值等于割容量”作为最优证书。

## 从一个计算问题开始

把仓库、道路或带宽看成有容量的有向边。我们希望从源点 $s$ 向汇点 $t$ 传尽量多的货，但中间节点不能凭空制造或吞掉货物。贪心地沿一条可用路径塞满会出错：早期选择可能占用本该留给另一条路径的边。残量网络中的反向边正是“撤回部分旧决定”的机制。

## 定义与符号

对边 $(u,v)$，容量为 $c(u,v)\ge0$，流为 $f(u,v)$。可行流满足容量约束

$$0\le f(u,v)\le c(u,v),$$

并在每个非 $s,t$ 节点满足流守恒：入流等于出流。流值为源点净流出 $|f|$。

残量容量包括尚可正向发送的 $c_f(u,v)=c(u,v)-f(u,v)$，以及可撤回的反向容量 $c_f(v,u)=f(u,v)$。只看未满的原始边会错过“先撤回、再重排”的可行改进。

一个 $s$-$t$ 割是顶点划分 $(S,T)$，其中 $s\in S,t\in T$；容量为

$$c(S,T)=\sum_{u\in S,v\in T}c(u,v).$$


## 从增广路到最优证书

若残量网络存在 $s$ 到 $t$ 的路径 $P$，令瓶颈为 $\Delta=\min_{(u,v)\in P}c_f(u,v)$。沿正向边增加、沿反向边减少 $\Delta$，仍满足容量和守恒，且流值增加 $\Delta$。这就是增广不变量。

当 BFS 找不到残量路径时，令 $S$ 为残量网络中从 $s$ 可达的顶点，$T=V\setminus S$。所有 $S\to T$ 原始边都已饱和，否则可达集合还能扩张；所有 $T\to S$ 原始边的流为零，否则存在反向残量边。因此

$$|f|=c(S,T).$$

任意流都不可能超过任意割容量，而此时我们的流恰好等于一个割，故它同时是最大流和最小割。这是算法输出可以被独立审计的原因。

## 手算一轮与反向边

设 $s\to a$ 容量 3、$s\to b$ 容量 2、$a\to b$ 容量 1、$a\to t$ 容量 2、$b\to t$ 容量 3。BFS 首先可增广 $s\to a\to t$ 两单位。之后边 $a\to t$ 饱和，但仍可走 $s\to b\to t$ 两单位，再走 $s\to a\to b\to t$ 一单位，总流为 5。若某个较差选择用掉 $a\to b$，反向残量边允许在后续路径中抵消它。

## 可运行实现

```python
from projects.algorithm_lab.max_flow import max_flow

edges = [(0, 1, 3.0), (0, 2, 2.0), (1, 2, 1.0), (1, 3, 2.0), (2, 3, 3.0)]
value, source_side, trace = max_flow(4, edges, 0, 3)
assert value == 5.0
print(source_side, trace[-1])
```

运行 `python -m unittest projects.algorithm_lab.test_max_flow`。实现以 BFS 选择最短（边数）增广路，因此是 Edmonds–Karp；它返回每次路径、瓶颈和累积流，以及最终残量图中的源侧集合。测试验证最大流等于割容量、平行边累加、不可达汇点，以及负容量/非法端点会被拒绝。

Edmonds–Karp 的最坏时间复杂度为 $O(VE^2)$，空间为 $O(V^2)$（此教学实现用稠密残量矩阵）。大型稀疏网络应使用邻接表和适合规模的成熟实现。

## 失败案例与工程边界

- **无反向边**：会把局部选择错误锁死，不能保证最大流。
- **浮点容量**：理论证明通常在精确算术下表述；浮点数需容差并注意累积误差。本实现适合小整数或可精确表示的小数例子。
- **源汇相同**：流值的定义退化，代码明确拒绝。
- **把最大流当作唯一建模答案**：时间窗、成本、多商品、动态容量都需要扩展模型。

## 常见误区

- **“每条增广路都必须最优”**：单条路径不是目标；残量网络保证可以修正历史选择。
- **“找不到新原始路径就结束”**：必须在残量图上判断。
- **“最小割就是删最少边”**：割最小化的是容量和，不是边数。
- **“BFS 是为了最短路”**：这里它用来获得 Edmonds–Karp 的复杂度界和稳定轨迹，不是在优化运输距离。

## 练习

1. **基础**：为手算网络列出第一次增广后的正向和反向残量容量。
2. **推导**：证明流值不超过任意 $s$-$t$ 割的容量。
3. **编码**：在轨迹中加入每次增广后的可达集合，并测试最终集合的割容量等于流值。
4. **开放**：把二分图匹配规约为单位容量最大流，说明匹配边、源边、汇边分别代表什么。
