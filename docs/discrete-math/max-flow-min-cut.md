# 最大流最小割：残量网络为何能证明最优

## 学习目标

读完后，你能定义可行流、残量网络与割；用一个实际的重排例子解释反向残量边；由流守恒推导“任意流不超过任意割”的弱对偶；实现 BFS 选增广路的 Edmonds–Karp；并用“流值等于割容量”作为最优证书。

## 从一个计算问题开始

把仓库、道路或带宽看成有容量的有向边。我们希望从源点 $s$ 向汇点 $t$ 传尽量多的货，但中间节点不能凭空制造或吞掉货物。贪心地沿一条可用路径塞满会出错：早期选择可能占用本该留给另一条路径的边。残量网络中的反向边正是“撤回部分旧决定”的机制。

## 定义与符号

对边 $(u,v)$，容量为 $c(u,v)\ge0$，流为 $f(u,v)$。可行流满足容量约束

$$0\le f(u,v)\le c(u,v),$$

并在每个非 $s,t$ 节点满足流守恒：入流等于出流。流值为源点净流出 $|f|$。

残量容量包括尚可正向发送的 $c_f(u,v)=c(u,v)-f(u,v)$，以及可撤回的反向容量 $c_f(v,u)=f(u,v)$。只看未满的原始边会错过“先撤回、再重排”的可行改进。

一个 $s$-$t$ 割是顶点划分 $(S,T)$，其中 $s\in S,t\in T$；容量为

$$c(S,T)=\sum_{u\in S,v\in T}c(u,v).$$

## 反向残量边不是回路：它会撤销一笔历史流

先看一个容量全为 $1$ 的网络：

$$
s\to a,\quad s\to b,\quad a\to b,\quad a\to t,\quad b\to t.
$$

若一个任意的增广路选择先走 $s\to a\to b\to t$，流值暂时是 $1$。此时 $a\to b$、$b\to t$ 已满；只查看未满的原边，会误以为只能再从 $s\to b$ 出发，却到不了 $t$。但流经 $a\to b$ 的那 $1$ 单位可以撤回，因此残量图有反向边 $b\to a$。第二条残量路正是

$$
s\to b\to a\to t.
$$

沿它增广 $1$ 后，$b\to a$ 的含义不是让货物真的逆向运输，而是把 $f(a,b)$ 从 $1$ 减到 $0$。最终留下两条不冲突的流 $s\to a\to t$ 与 $s\to b\to t$，总流为 $2$。所以反向边表达的是**对当前流的代数修正权**。

这个例子解释了为什么一般 Ford--Fulkerson 必须维护反向边；它并不说 Edmonds--Karp 的 BFS 必会先选那条较差的三边路径。BFS 的职责是固定为最短边数增广路，从而带来复杂度界；反向边的职责始终是保留所有可行的重排。

## 正确性推导：从增广路到最优证书

若残量网络存在 $s$ 到 $t$ 的路径 $P$，令瓶颈为 $\Delta=\min_{(u,v)\in P}c_f(u,v)$。沿正向边增加、沿反向边减少 $\Delta$，仍满足容量和守恒，且流值增加 $\Delta$。这就是增广不变量。

### 弱对偶：任何可行流都不能穿过割容量

固定任意一个 $s$-$t$ 割 $(S,T)$。把 $S$ 内每个顶点的“流出减流入”相加：$S$ 内部边作为一次流出和一次流入恰好抵消；除源点外的 $S$ 内部顶点由流守恒贡献零；$t\notin S$。留下的正是流值：

$$
\begin{aligned}
|f|
&=\sum_{u\in S,\,v\in T}f(u,v)
  -\sum_{u\in T,\,v\in S}f(u,v)\\
&\le\sum_{u\in S,\,v\in T}f(u,v)\\
&\le\sum_{u\in S,\,v\in T}c(u,v)
=c(S,T).
\end{aligned}
$$

第一步是“跨割净流”恒等式，第二步只用了反向穿越流非负，第三步只用了容量约束。它对**每一份**可行流和**每一个**割都成立，因此给出了最大流的上界与最小割的下界；这就是弱对偶。

### 终止时的等式：残量可达集给出一个紧的割

当 BFS 找不到残量路径时，令 $S$ 为残量网络中从 $s$ 可达的顶点，$T=V\setminus S$。因为 $t$ 不可达，$t\in T$。

- 对每条原边 $u\in S,v\in T$，若还剩 $c(u,v)-f(u,v)>0$ 的正向残量，$v$ 就应可达。这不可能，所以它已饱和：$f(u,v)=c(u,v)$。
- 对每条原边 $u\in T,v\in S$，若 $f(u,v)>0$，残量图就有反向边 $v\to u$，会把可达集从 $S$ 扩到 $T$。这也不可能，所以 $f(u,v)=0$。

代回跨割净流恒等式便得到

$$
|f|=\sum_{S\to T}f-\sum_{T\to S}f
=\sum_{S\to T}c-0=c(S,T).
$$

弱对偶说任何可行流都不能超过任何割；这里的一份流恰好等于一个割，故它同时是最大流和最小割。这也是算法输出可以被独立审计的原因：证书不只报一个数，而是给出可重放的增广轨迹和最终残量可达集。

## 手算 Edmonds--Karp 与最小割

设 $s\to a$ 容量 3、$s\to b$ 容量 2、$a\to b$ 容量 1、$a\to t$ 容量 2、$b\to t$ 容量 3。按邻接扫描顺序，BFS 可以依次找到：

| 增广路 | 瓶颈 | 累积流 |
| --- | ---: | ---: |
| $s\to a\to t$ | 2 | 2 |
| $s\to b\to t$ | 2 | 4 |
| $s\to a\to b\to t$ | 1 | 5 |

最后从 $s$ 出发没有正残量边，故 $S=\{s\}$；割容量为 $c(S,T)=3+2=5$，与流值相等。请把这里的“具体 BFS 轨迹”和上一节“任意坏路径需要反向修正”的角色分开：前者展示确定实现的证书，后者解释残量定义不能省略。

## 可运行实现

```python
from projects.algorithm_lab.max_flow import max_flow, max_flow_certificate

edges = [(0, 1, 3.0), (0, 2, 2.0), (1, 2, 1.0), (1, 3, 2.0), (2, 3, 3.0)]
value, source_side, trace = max_flow(4, edges, 0, 3)
assert value == 5.0
assert max_flow_certificate(4, edges, 0, 3, value, source_side, trace)["valid"]
print(source_side, trace[-1])
```

运行 `python -m unittest projects.algorithm_lab.test_max_flow`。实现以 BFS 选择最短（边数）增广路，因此是 Edmonds–Karp；它返回每次路径、瓶颈和累积流，以及最终残量图中的源侧集合。`max_flow_certificate` 会重放每条增广路径与最终源侧集合，并独立计算该集合跨出的原始容量；篡改路径、瓶颈、累积流或割都会失败。测试验证最大流等于割容量、平行边累加、不可达汇点，以及负容量/非法端点会被拒绝。

在邻接表实现中，Edmonds--Karp 每次 BFS 为 $O(E)$。每次增广至少饱和一条最短路上的边；一条边若在以后因反向残量重新变成关键边，它到源的 BFS 层数至少增加 $2$，故一条边至多成为关键边 $O(V)$ 次。于是增广次数为 $O(VE)$，总时间为 $O(VE^2)$。

本教学实现为了把残量状态直接放进矩阵，BFS 会扫描每个出队顶点的全部 $V$ 个候选邻点，单次为 $O(V^2)$；保守地说，总代价为 $O(V^3E)$，空间为 $O(V^2)$。这不是把矩阵实现伪装成邻接表界的细节：大型稀疏网络应使用邻接表和适合规模的成熟实现。

## 失败案例与工程边界

- **无反向边**：会把 $s\to a\to b\to t$ 一类局部选择锁死，不能保证最大流。
- **浮点容量**：理论证明通常在精确算术下表述；浮点数需容差并注意累积误差。本实现适合小整数或可精确表示的小数例子。
- **源汇相同**：流值的定义退化，代码明确拒绝。
- **把最大流当作唯一建模答案**：时间窗、成本、多商品、动态容量都需要扩展模型。

## 常见误区

- **“每条增广路都必须最优”**：单条路径不是目标；残量网络保证可以修正历史选择。
- **“找不到新原始路径就结束”**：必须在残量图上判断。
- **“最小割就是删最少边”**：割最小化的是容量和，不是边数。
- **“最小割一定唯一”**：不对；同一最大流网络可有多个容量相同的最小割。证书重放的是该 Edmonds–Karp 轨迹产生的源侧集合，而不是声称它是唯一划分。
- **“BFS 是为了最短路”**：这里它用来获得 Edmonds--Karp 的复杂度界和稳定轨迹，不是在优化运输距离。
- **“残量反向边表示真实的反向运输”**：不必如此解释；它首先表示可把先前的 $f(u,v)$ 减少多少。

## 练习

1. **基础**：为“先走 $s\to a\to b\to t$”的单位容量网络列出所有正、反向残量边，并手算第二条增广路。
2. **推导**：对任意割逐项证明跨割净流恒等式；指出内部边为何消失。
3. **证明**：从最终残量可达集出发，分别证明 $S\to T$ 边饱和和 $T\to S$ 边零流，再推出强对偶等式。
4. **编码**：在轨迹中加入每次增广后的可达集合，并测试最终集合的割容量等于流值。
5. **开放**：把二分图匹配规约为单位容量最大流，说明匹配边、源边、汇边分别代表什么。

## 练习答案提示

1. 第一次后 $b\to a$ 的反向残量为 $1$；走 $s\to b\to a\to t$ 时，只有中间这一步减少 $f(a,b)$，最后两条直通 $t$ 的边各承载 $1$。
2. 对 $S$ 中每个顶点求“流出减流入”；内部边出现一次正项、一次负项。非源点守恒，只剩源的 $|f|$ 与跨边两组项。
3. 正向残量大于零会让 $T$ 中顶点可达；反向残量大于零会让原来在 $T$ 的边尾可达。两种矛盾分别给出饱和与零流，代入弱对偶链即可。
4. 每轮 BFS 后记录残量图中从源可达的顶点；最终不可达汇时，源侧到补集的原边容量和应与累计流值在容差内相等。
5. 源连左部、右部连汇、原二分边连左右部且容量均为 1；整数最大流中单位流经过一条中间边就对应一条不共享端点的匹配。
