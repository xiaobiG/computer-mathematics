# 递推关系与分治复杂度

递归算法的时间常由“子问题数量、子问题规模、合并代价”决定。归并排序将 $n$ 个元素拆成两个规模为 $n/2$ 的问题，合并代价为 $O(n)$：

$$T(n)=2T(n/2)+O(n)$$

每一层合并总量为 $O(n)$，层数为 $\log_2n$，因此总时间为 $O(n\log n)$。

## 主定理的直觉

对于 $T(n)=aT(n/b)+f(n)$，比较递归树的叶子工作量 $n^{\log_ba}$ 与每层额外工作 $f(n)$：谁增长更快，谁通常主导总复杂度。

## 不要机械套公式

主定理只覆盖特定形态。子问题不等分、递归深度依赖数据、或合并工作不规则时，应从递归树、代入法或更一般的工具出发。

## 练习

分析二分查找的递推式 $T(n)=T(n/2)+O(1)$，并与归并排序比较为什么一个是 $O(\log n)$、另一个是 $O(n\log n)$。
