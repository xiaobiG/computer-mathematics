# 离散数学深度版路线

## 主题目标

离散数学深度版让读者不止记住算法步骤，还能写出不变量、终止性论证、复杂度分析与反例。每篇文章采用[深度文章模板](/templates/deep-lesson)，并连接到[算法可视化实验室](/projects/algorithm-lab)。

## 分层路线

| 层级 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 命题逻辑、量词、集合、归纳法 | 计划新增 |
| 1 | 递推、复杂度、图的连通性与树 | 既有文章待深化 |
| 2 | 循环不变量、BFS/DFS、最短路、并查集、贪心与动态规划 | 循环不变量、BFS、递推、Dijkstra、并查集、贪心与动态规划已完成 |
| 3 | 负权、输入规模、测试预言、可视化与可计算性 | Bellman–Ford 已深化；其余由项目持续扩展 |

## 发布顺序

1. [循环不变量](/discrete-math/loop-invariants)：证明模板与二分查找；
2. [Dijkstra](/discrete-math/dijkstra)：贪心正确性与负权边界；
3. BFS 与并查集：图不变量、复杂度和测试；DFS 待补齐；
4. 递推关系与主定理：递归树和边界条件；
5. 贪心交换论证与动态规划状态设计：新增主干；
6. Bellman–Ford、拓扑排序、P/NP 直觉：作为工程与前沿层。

## 本专题验收

- 每个核心算法给出适用前提、正确性论证和复杂度；
- 每个算法至少有一个会失败的输入或反例；
- 练习分为基础、推导、编码、开放四层；
- 项目测试覆盖边界图、不可达节点与违反前提的输入。

## 练习

1. 为 BFS 写出一个与距离分层有关的不变量。
2. 找到一个 Dijkstra 必须失败的负权例子，并用 Bellman–Ford 验证。
3. 为并查集设计随机操作的属性测试。
4. 说明“算法通过所有测试”为什么不等价于“算法已被证明正确”。
