# 编辑与发布流程

## 1. 选题定位

先在学习路线中确认文章的前置知识和后续用途。一个合格选题必须回答：读者为什么在计算机实践中需要它？它连接哪一个算法、模型或工程问题？

## 2. 撰写正文

课程正文必须包含：

1. 一个计算问题或反直觉现象；
2. 直觉解释与严谨定义；
3. 必要的推导、公式或伪代码；
4. 工程边界、误区或反例；
5. 可执行的练习及简短答案提示。

使用 [写作规范](/contributing) 中的模板；核心文章采用 [深度文章模板](/templates/deep-lesson)。只有文章完成并通过核对后，才在所属专题的侧边栏添加入口。

## 3. 内容校验

运行：

```bash
npm run content:check
npm run projects:test
```

第一条检查会确认每篇课程正文都有标题、描述、唯一一级标题、二级结构和练习章节；第二条会运行所有综合项目的单元测试。二者都不能替代事实与推导的人工审阅。

## 4. 构建与发布

```bash
npm run build
```

构建会先执行内容校验和项目测试，再生成 VitePress 站点。发布前确认新文章的导航、交叉链接和公式渲染均符合预期。

## 发布清单

- 文章属于正确专题，且在侧边导航中可找到。
- 术语表、前置文章和后续文章有必要链接。
- 示例代码表达的是教学原理，不误导为生产实现。
- 四层练习分别提供起始公式、验收条件、测试不变量或报告口径等提示，而不直接替读者完成推导。
- 密码学和数值计算内容明确说明适用边界。
