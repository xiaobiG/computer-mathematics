# 集合与数组形状：成员关系为何不是索引

## 学习目标

你将能区分集合的成员语义与数组的有序位置；计算并、交、差；解释二维数组形状为何写作 `(行数, 列数)`；并用从 0 开始的坐标、安全的矩形检查和重放证书审计一个查询。

## 从一个程序错误开始

若 $A=\{1,2,3,4\}$、$B=\{3,4,5\}$，则 $3\in A\cap B$。这个断言不关心你先写 3 还是先写 1：集合描述“是否是成员”。但二维数组

$$M=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}$$

中 `M[1][1]` 是 5，`M[0][1]` 是 2。这里的数字位置是语义的一部分，交换行或列会改变对象。把集合当数组会错误依赖顺序；把数组当集合会丢掉形状、重复和坐标。

## 直觉与定义：无序成员、有序坐标

有限集合的三种基本运算为

$$A\cup B=\{x:x\in A\lor x\in B\},\quad A\cap B=\{x:x\in A\land x\in B\},\quad A\setminus B=\{x:x\in A\land x\not\in B\}.$$

数组则是一个从坐标到值的函数。形状为 $(r,c)$ 的二维数组定义在

$$\{0,\ldots,r-1\}\times\{0,\ldots,c-1\}.$$

因此 `(2, 3)` 表示 2 行、3 列，合法行索引是 0、1，合法列索引是 0、1、2。半开区间与 Python 的 `range(r)` 完全一致；访问行 2 或列 3 是定义域外，不是“最后一个元素”。

## 正确性与复杂度

集合运算直接按照量词定义筛选成员；对总共 $n$ 个已验证成员，哈希集合的期望查找与并交差构造为 $O(n)$。排序输出额外花费 $O(n\log n)$，它服务于可重放文本，而非算法本体。

矩形数组的形状检查首先固定第一行宽度 $c$，再验证每一行长度都等于 $c$；坐标检查就是验证 $0\le i<r$ 与 $0\le j<c$。因此一旦合同接受，`values[i][j]` 落在定义域内，恰好给出声明坐标对应的值。

## 失败案例与工程边界

- **重复元素。** 数学集合会自动合并重复项；本教学合同反而拒绝它们，迫使调用者先决定自己是在表达集合还是列表/多重集。
- **锯齿列表。** `[[1,2],[3]]` 在 Python 可以存在，却没有单一的二维矩形形状；不要把它标成 `(2,2)`。
- **负索引。** Python 的 `-1` 有“从末尾”便利语义，但线性代数和多数张量 API 的数学坐标通常要求非负；本合同刻意拒绝负坐标。
- **张量与广播。** 真实数组库还包含 dtype、轴、步幅、广播和批次维度。本页只建立二维矩形与坐标的最小语言。

## 常见误区

- **“集合的第 0 个元素。”** 数学集合没有位置；若需要位置，应使用列表、元组或数组。
- **“形状 (2,3) 表示 3 行 2 列。”** 错。惯例是先行后列，`shape[0]` 是第一轴大小。
- **“数组里出现相同值就能当集合。”** 错。`[1,1,2]` 保留重复和顺序，转换为集合会丢失信息。
- **“索引 1 是第一项。”** 对 Python/NumPy 默认是第二项；必须先确认索引原点。

## 练习

1. 计算 $\{a,b,c\}\cap\{b,c,d\}$、两个方向的差集，并说明为何差集不交换。
2. 写出形状为 `(3, 2)` 的所有合法坐标；用半开区间表示它们。
3. 构造一个在 Python 中可用但被本课程矩形合同拒绝的嵌套列表，解释拒绝理由。
4. 将一个包含重复元素的列表转成集合，再转回排序列表；列出哪些信息不可恢复。

## 练习答案提示

1. 交集为 $\{b,c\}$；左差为 $\{a\}$、右差为 $\{d\}$，条件中的“在左不在右”改变了方向。
2. 行是 `range(3)`，列是 `range(2)`；坐标为所有这两个范围的有序对。
3. 例如 `[[1, 2], [3]]`；两行宽度不同，不能用一个列数定义第二轴。
4. 元素所属关系还在，但出现次数和原始相对顺序已丢失；这正是集合转换的语义成本。
