# 术语表

| 术语 | 简明含义 | 相关专题 |
| --- | --- | --- |
| 向量 | 有序数值列表，可表示方向、特征或状态 | 线性代数 |
| 矩阵 | 表示线性变换或二维数据的数表 | 线性代数 |
| 点积 | 两个向量方向一致程度的标量度量 | 线性代数 |
| 循环不变量 | 每次循环前后保持成立的命题 | 离散数学 |
| 渐进复杂度 | 输入规模增长时的资源增长率 | 离散数学 |
| 条件概率 | 已知一个事件发生时另一个事件的概率 | 概率论 |
| 似然 | 固定观测数据后，参数对数据的解释程度 | 概率论 |
| 浮点数 | 有限位近似表示的实数 | 数值计算 |
| 条件数 | 输入微小变化会被解放大的程度 | 数值计算 |
| 同余 | 除以同一模数后余数相同的关系 | 数论 |
| 模逆元 | 模意义下与某数相乘得到 1 的数 | 数论 |
