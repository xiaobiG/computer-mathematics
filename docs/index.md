## 如何阅读

每篇文章都遵循同一条路径：**问题直觉 → 严谨定义 → 推导 → 可运行代码 → 工程边界 → 练习**。不把数学当成公式清单，而是把它变成可验证、可复用的工具。

> 先理解一个概念解决什么计算问题，再学习它如何被证明和实现。
