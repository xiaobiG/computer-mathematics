# 特征值与 PCA：寻找数据变化最大的方向

若矩阵 $A$ 作用在非零向量 $v$ 上只改变长度、不改变方向，则：

$$Av=\lambda v$$

$v$ 是特征向量，$\lambda$ 是特征值。对数据的协方差矩阵而言，特征向量给出数据变化的主方向，特征值表示沿该方向的方差大小。

## PCA 的步骤

1. 将每个特征减去均值；
2. 计算协方差矩阵；
3. 取最大若干特征值对应的特征向量；
4. 将数据投影到这些方向。

保留最大的方向等价于在给定维数下保留尽可能多的方差，并最小化正交投影的重构误差。

## 工程边界

PCA 假设“方差大”有价值；它对尺度敏感，通常需先标准化特征。非线性结构可能需要其他降维方法。

## 练习

对一组二维点先中心化，再用主方向投影到一维。观察保留第一主成分前后的重构误差。
