# 高斯消元：解线性方程组

## 学习目标

- 将 $Ax=b$ 化为增广矩阵并消元；
- 解释部分选主元为何改善浮点计算；
- 区分唯一解、无解与无穷多解。

## 从一个计算问题开始

电路、约束布局和回归都会生成方程组。对 $2x+y=5,\ x-y=1$，消元将“同时满足”变成可逐行回代的三角结构。

## 定义与推导

在 $[A\mid b]$ 上交换两行、非零倍乘一行或一行加另一行的倍数都不改变解集。对例子做 $R_1\leftarrow R_1-2R_2$，得 $3y=3$，所以 $y=1,x=2$。出现 $[0\ 0\mid c]$、$c\ne0$ 表示无解；全零行且变量多于主元表示有自由变量。

## 把算法实现为代码

```python
def solve_2x2(a, b, c, d, u, v):
    if abs(a) < 1e-12:
        a, b, c, d, u, v = c, d, a, b, v, u
    factor = c / a
    y = (v - factor * u) / (d - factor * b)
    return ((u - b * y) / a, y)

assert solve_2x2(2, 1, 1, -1, 5, 1) == (2.0, 1.0)
```

密集 $n\times n$ 系统消元耗时 $O(n^3)$，回代为 $O(n^2)$。[线性代数实验室](/projects/linear-algebra-lab)提供带部分选主元的通用实现。

## 失败案例与工程边界

每一步行变换保持解集，最终三角系统与原系统同解；回代依次满足各方程。小主元会放大舍入误差，部分选主元选择当前列绝对值最大的候选行；病态问题仍可能需要 QR、SVD 或正则化。

## 常见误区

- 把接近零的浮点数当作严格零。
- 只在失败时换行，而非每列选主元。
- 将奇异矩阵误认为数据必然错误。

## 练习

1. 对 $x+y=2,\ 2x+2y=4$ 消元并识别自由变量。
2. 构造出现 $[0\ 0\mid c]$ 的矛盾系统。
3. 比较启用与禁用选主元的小主元输入。
