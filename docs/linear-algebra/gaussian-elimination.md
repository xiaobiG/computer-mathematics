# 高斯消元：解线性方程组

## 把方程写成矩阵

方程组 $Ax=b$ 可写成增广矩阵 $[A\mid b]$。交换两行、某行乘以非零常数、某行加上另一行的倍数，都不会改变解集。

目标是将主元下方消为零，得到上三角矩阵，再自下而上回代。

```python
def solve_2x2(a, b, c, d, u, v):
    # ax + by = u; cx + dy = v
    factor = c / a
    d2, v2 = d - factor * b, v - factor * u
    y = v2 / d2
    x = (u - b * y) / a
    return x, y
```

## 主元与稳定性

若主元很小，除法会放大舍入误差。实际实现通常使用**部分选主元**：在当前列选择绝对值最大的行交换到主元位置。

## 工程连接

最小二乘、物理仿真和图形计算都会归结为线性方程。对大型稀疏问题，直接消元常不够高效，需要专门的分解或迭代法。

实现带部分选主元的通用消元；为无解和无穷多解分别设计检测逻辑。
