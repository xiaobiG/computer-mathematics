# 线性组合、基与维度：数据为何能被压缩

## 学习目标

- 判断一个向量能否由已有方向组合出来；
- 区分生成空间、线性无关、基和维度；
- 将基与矩阵列空间、秩、降维联系起来。

## 从一个计算问题开始

日志的三个特征是“请求数、成功数、失败数”，但失败数总等于请求数减成功数。保存三列是否重复保存信息？关键在于第三个方向能否由前两个方向的线性组合表示。

## 定义与推导

向量 $b$ 能由 $v_1,\ldots,v_k$ 表示，当且仅当存在实数 $c_i$ 使

$$b=c_1v_1+\cdots+c_kv_k.$$

所有这样的组合称为 $\operatorname{span}(v_1,\ldots,v_k)$。若只有全零系数才能组合出零向量，这组向量线性无关；既生成整个空间又线性无关的集合是一组基，基中向量数为维度。

## 手算一个完整例子

令 $v_1=(1,0)$、$v_2=(0,1)$、$v_3=(1,1)$。有 $v_3=v_1+v_2$，所以三个方向并不独立，二维平面仍只需要两个基向量。$b=(4,3)$ 可写成 $4v_1+3v_2$。

把方向作为矩阵列，所有 $Ax$ 的集合称为列空间；列空间的维度是秩。消元中的主元列正是原列空间的一组基。

## 代码实验与复杂度

```python
def reconstruct(c1, c2):
    return (c1, c2)  # 基 (1, 0)、(0, 1) 下的坐标重构

assert reconstruct(4, 3) == (4, 3)
```

判断 $b$ 是否属于列空间，就是解 $Ax=b$，密集情形可由消元在 $O(n^3)$ 时间完成。数据近似可表示时转向最小二乘，而不是强行判断“无解”。

## 失败案例与工程边界

测量噪声会使 $b$ 不在列空间中；“近似相关”也不等于代数上严格相关。浮点数下主元是否为零取决于尺度和容差。PCA、SVD 的价值正是在保留少数方向时量化这种近似误差。

## 常见误区

- 向量数量多不代表维度高，新增向量可能冗余。
- 基不唯一；不同基可以描述同一空间。
- 独立性是精确结论，不代表数值计算稳定。

## 练习

1. 求 $(2,3)$ 在 $(1,1)$、$(1,-1)$ 下的坐标。
2. 说明 $(1,0)$、$(2,0)$ 为什么不能成为二维平面的基。
3. 为三个高度相关的数据列预测删除一列对秩的影响。
