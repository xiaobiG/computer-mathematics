# 低秩图像压缩：把 SVD 变成可验证实验

## 学习目标

读完后，你能将灰度图表示为矩阵；解释截断 SVD 为什么给出 Frobenius 范数下最佳秩 $k$ 近似；计算原矩阵与低秩因子的存储量；运行逐次秩一残差提取；并识别迭代收敛、像素编码与生产图像压缩的边界。

## 从一个计算问题开始

一张 $m\times n$ 灰度图有 $mn$ 个像素。若画面主要由平滑背景、少量轮廓和重复纹理构成，像素并非完全独立：或许只需少数“纵向模式”与“横向模式”的组合即可近似重构。问题是：如何以可测量的误差换取更少的参数，而不是凭眼睛猜测？

把像素值放入矩阵 $A\in\mathbb R^{m\times n}$。低秩近似要求找 $\hat A$，使 $\operatorname{rank}(\hat A)\le k$，同时让误差尽可能小。$k$ 是质量和存储的显式旋钮。

## 截断 SVD 的推导

若

$$A=U\Sigma V^T=\sum_{i=1}^r\sigma_i u_i v_i^T,qquad
\sigma_1\ge\cdots\ge\sigma_r>0,$$

则第 $k$ 个截断为

$$A_k=\sum_{i=1}^k\sigma_i u_i v_i^T.$$

Eckart–Young–Mirsky 定理说明，在所有秩最多为 $k$ 的矩阵中，$A_k$ 最小化 Frobenius 误差，并且

$$\|A-A_k\|_F^2=\sum_{i=k+1}^r\sigma_i^2.$$

这也解释了“奇异值衰减快时适合压缩”：尾部平方和小，丢弃它们的能量损失小。请注意最优性针对实值矩阵和 Frobenius 范数；它不保证人眼感知质量、文件格式大小或下游识别性能最优。

## 从一个秩一分量到逐次残差

教学项目先用 $A^TA$ 的幂迭代找主右奇异向量 $v_1$，计算

$$Av_1=\sigma_1u_1,\qquad A^{(1)}=A-\sigma_1u_1v_1^T.$$

再对残差 $A^{(1)}$ 重复，得到近似的多项之和。理论 SVD 中各项正交；该小型实现使用浮点迭代和残差消去，适合观察概念，并非数值最稳健的 SVD 算法。

## 算法实现：压缩一个灰度矩阵

```python
from projects.linear_algebra_lab.main import compress_grayscale, low_rank_parameter_report

pixels = [[8.0, 0.0], [0.0, 3.0]]
components, approximation, error = compress_grayscale(pixels, rank=1, iterations=120)

print(len(components))
print(approximation)
print(error)
print(low_rank_parameter_report(2, 2, rank=1))
```

`compress_grayscale` 每轮从当前残差抽取一个秩一部分，并返回分量、重构矩阵和 $\|A-\hat A\|_F$。`low_rank_parameter_report` 同时返回密集参数数、低秩参数数、差额和是否真的节省参数；这样“压缩”不再只是名称。完整测试：

```bash
python -m unittest projects.linear_algebra_lab.test_main
```

对小图，原始存储量为 $mn$ 个数；保存 $k$ 个秩一项需要约 $k(m+n+1)$ 个数（左右向量与奇异值）。只有当

$$k(m+n+1)<mn$$

时，按这种朴素参数计数才有压缩空间。实际文件还需量化、编码、元数据和传输开销。

## 正确性与复杂度

秩一项 $\sigma uv^T$ 的秩至多为一；$k$ 项之和的秩至多为 $k$，故实现的输出满足低秩约束。每一步都把该项从残差中扣除，所以不变量是

$$A=\hat A^{(t)}+R^{(t)}.$$

测试验证秩二对角矩阵会被两项近似重构，且在给定小例上，保留两项的误差不高于保留一项。幂迭代每轮需矩阵—向量乘法，约为 $O(mn)$；提取 $k$ 项、每项迭代 $T$ 次约为 $O(kTmn)$，额外使用密集 $O(mn)$ 残差。

若将压缩结果用于检索，`compressed_image_search` 会以同一秩压缩查询和图库，再在压缩域计算余弦相似度，并返回每幅图的重构误差。它同时保留原始域和压缩域的排名，检查两份结果是否都是图库编号的排列、首名是否保持、完整排名是否保持。对 $g$ 幅同形图，这个教学流程约为 $O((g+1)kTmn)$，之后排序为 $O(g\log g)$。这些证书只描述这个像素余弦示例的排名一致性；小 Frobenius 误差或首名保持都不能证明人物、物体或语义相似度仍被保留。

## 失败案例与工程边界

- **谱间隙小**：前两个奇异值接近时，幂迭代收敛慢，有限迭代下方向可能不准。
- **不断言单调性**：理论截断 SVD 的误差随 $k$ 不增；近似、有限迭代的残差消去要用测试和误差记录审查，不能盲信。
- **像素范围**：重构值可能超出 `[0, 255]`，输出前的裁剪和量化会额外引入误差。
- **“低秩就是图像格式”**：JPEG、WebP、AVIF 使用专门变换、量化和熵编码；本实验不读取、不写入图像文件，也不替代它们。
- **病态与大矩阵**：应使用 NumPy/SciPy 的截断 SVD、随机 SVD 或稀疏算法，并报告容差和收敛诊断。

## 常见误区

1. “秩 $k$ 就是保留任意 $k$ 行或列。”错误：它是 $k$ 个全局模式的组合。
2. “误差小一定肉眼更好。”错误：Frobenius 误差不包含视觉感知和任务需求。
3. “逐次幂迭代等于精确 SVD。”错误：它是小规模教学近似，受迭代次数和谱间隙影响。
4. “参数更少一定文件更小。”错误：需计入量化、编码和元数据。

## 练习

2. **推导题**：由 SVD 的正交性推导 $\|A-A_k\|_F^2=\sum_{i>k}\sigma_i^2$。
3. **编码题**：为 `compress_grayscale` 加入输入像素范围检查，并比较裁剪前后的误差。
4. **开放题**：设计一套压缩实验报告：包含数据来源、秩、迭代次数、误差、参数量、运行时间及何时必须改用生产库。

## 练习答案提示

1. 原图有 $64$ 个参数；秩 $k$ 的表示可按 $k(m+n+1)$ 估计，代入 $m=n=8$ 后再比较何时小于 64。
2. 将 $A=\sum_i\sigma_i u_iv_i^T$ 与 $A_k$ 相减；正交项的 Frobenius 内积为零，所以平方范数分解为被舍弃奇异值平方和。
3. 先约定合法范围与超界策略；分别记录原始重构误差、裁剪后误差及是否发生裁剪，避免把输出处理混入低秩算法误差。
4. 每份报告要使他人能复跑：数据、随机种子/迭代、参数、误差定义、资源和停止条件都不能省略；规模大或诊断失败时切换受审计的数值库。
