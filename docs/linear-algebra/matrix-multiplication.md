# 矩阵乘法：连续变换如何合成为一步

## 为什么规则是“行乘列”

矩阵 $A$ 把输入向量 $x$ 变为 $Ax$。若随后再施加 $B$，结果为 $B(Ax)$。我们希望把连续两步写成一次变换 $(BA)x$，所以矩阵乘法必须满足这一组合关系。

令 $A$ 为 $m\times n$、$B$ 为 $n\times p$，则：

$$ (AB)_{ij}=\sum_{k=1}^{n}A_{ik}B_{kj} $$

内侧维度 $n$ 必须一致：$A$ 的每一行描述如何组合输入，而 $B$ 的每一列是一次输入的结果。

## 一个变换例子

在二维空间中，先把点横向拉伸两倍，再旋转 90°：

$$S=\begin{bmatrix}2&0\\0&1\end{bmatrix},\quad
R=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$$

组合变换是 $RS$，顺序不能交换；通常 $RS\ne SR$。

```python
def matmul(a, b):
    return [[sum(a[i][k] * b[k][j] for k in range(len(b)))
             for j in range(len(b[0]))]
            for i in range(len(a))]
```

## 工程连接

图形学中矩阵组合物体变换；神经网络用矩阵乘法同时计算一批样本；数据库和图计算则把关系或邻接关系编码为矩阵。

## 练习

手算 $RS$ 与 $SR$，并将点 $(1, 1)$ 分别代入，观察“先缩放再旋转”和“先旋转再缩放”的差异。
