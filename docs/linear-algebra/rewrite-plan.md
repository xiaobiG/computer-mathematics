# 第一期重写清单：程序员的线性代数

## 目标与完成定义

第一期不追求一次写完所有高阶理论，而是把现有“概念导读”升级为能支撑编程实践的学习闭环。每篇重写文章都必须满足 [深度文章模板](/templates/deep-lesson) 的核心要求：问题驱动、完整推导、手算验证、可运行代码、正确性或复杂度说明、反例与分层练习。

读者完成本期后，应能解释矩阵为何表示变换、在代码中判断维度和数值边界，并能将投影、分解与降维连接到实际任务。

## 补齐的基础节点

现有目录在“点积”与“矩阵变换”之间缺少线性组合、张成、基和维度。这一节点会作为第 2 周前的短篇插入，标题暂定为“线性组合、基与维度：数据为何能被压缩”。它将解释：

1. 向量空间中的“可表示性”如何对应特征冗余；
2. 基为何能给出坐标，以及维度为何约束独立信息的数量；
3. 这套语言如何自然导向矩阵列空间、秩、PCA 和 SVD。

新增文章完成后再加入专题导航，避免先产生无效链接。

## 发布核对

- 在重写前保留原文章的 URL，避免外部链接失效。
- 每一篇至少链接一篇前置文章和一项后续应用。
- 示例优先使用标准库；涉及大规模计算时说明应使用 NumPy、SciPy 或 BLAS，而非手写三重循环。
- 发布前运行 `npm run build`，并在浏览器确认公式、代码块和交叉链接。
