# SVD：矩阵的通用分解

任意实矩阵 $A\in\mathbb{R}^{m\times n}$ 都可分解为：

$$A=U\Sigma V^T$$

$U$ 与 $V$ 的列正交，$\Sigma$ 仅在对角线上有非负奇异值。它将矩阵看作：沿输入正交方向旋转、按不同尺度拉伸、再旋转到输出方向。

## 低秩近似

只保留最大的 $k$ 个奇异值，就得到秩为 $k$ 的近似 $A_k$。在 Frobenius 范数下，它是最佳低秩近似，因此可用于图像压缩、降噪和推荐系统。

## 与 PCA 的关系

对中心化数据矩阵做 SVD，右奇异向量给出主成分方向，奇异值平方与方差有关。SVD 不要求方阵，也无需先显式构造协方差矩阵。

## 练习

对一张灰度图矩阵保留不同数量的奇异值，比较文件大小、视觉质量和重构误差。
