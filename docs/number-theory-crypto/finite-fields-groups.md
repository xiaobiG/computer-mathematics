# 有限域、群与离散对数直觉

> Diffie–Hellman 不是“把指数算得很大”就安全。它依赖在一个精心选择的有限群里：正向幂运算容易，而从 \(g^a\) 反推 \(a\) 很难。本课先把这个“群”究竟是什么说清楚。

## 学习目标

- 区分环、域、群以及 \(\mathbb Z_n\) 与 \(\mathbb F_p\)；
- 证明模素数下每个非零元素都有乘法逆元；
- 计算元素阶、识别生成元，并解释循环群；
- 用快速幂实现小规模枚举实验；
- 明确小群、小子群与不验证公钥为何破坏密码协议。

## 从“为什么能除”开始

在普通整数中 \(6/4\) 不是整数；在模 12 意义下，方程 \(4x\equiv6\pmod {12}\) 甚至无解。但模 11 时，任意非零数都可以“除”：例如 \(4^{-1}\equiv3\pmod {11}\)，因为 \(4\cdot3\equiv1\)。

这个差异是密码学参数选择的第一道门槛。\(\mathbb Z_{12}\) 有零因子：\(3\cdot4\equiv0\)，所以不是域；当 \(p\) 为素数，\(\mathbb F_p=\mathbb Z_p\) 才是有限域。

## 群、域与乘法群

一个群 \((G,\circ)\) 满足封闭性、结合律、单位元和每个元素都有逆元；若 \(a\circ b=b\circ a\)，它是交换群。密码协议常在交换群中工作，以保证双方能得到相同共享值。

有限域 \(\mathbb F_p\) 同时有加法和乘法；非零元素集合

\[
\mathbb F_p^*=\{1,2,\ldots,p-1\}
\]

在模 \(p\) 乘法下构成群，大小为 \(p-1\)。为什么每个非零 \(a\) 都有逆元？因为 \(p\) 是素数，\(\gcd(a,p)=1\)，贝祖等式给出 \(au+pv=1\)，取模后 \(au\equiv1\pmod p\)。

对于复合模数 \(n\)，只有与 \(n\) 互素的元素属于单位群 \(\mathbb Z_n^*\)，其大小是欧拉函数 \(\varphi(n)\)，并非所有非零剩余类都能除。

## 元素阶、拉格朗日定理与生成元

群元素 \(g\) 的**阶** \(\operatorname{ord}(g)\) 是最小正整数 \(k\)，使 \(g^k=e\)。由拉格朗日定理，它整除有限群大小。因此在 \(\mathbb F_p^*\) 中有

\[
g^{p-1}\equiv1\pmod p
\]

（费马小定理）。若 \(g\) 的阶恰为 \(p-1\)，连续幂 \(g^0,g^1,\ldots,g^{p-2}\) 会恰好枚举整个乘法群，\(g\) 称为生成元，群称为循环群。

密码协议通常选择一个大素数阶子群 \(G=\langle g\rangle\)，而非随意使用全部元素。将秘密指数按子群阶 \(q\) 取值，能避免小子群把私钥信息逐位泄露。

## 离散对数：易算与难反算的不对称

给定 \(g\)、\(a\)、模数 \(p\)，计算 \(g^a\bmod p\) 可用重复平方在 \(O(\log a)\) 次模乘内完成。反向问题是：给定 \(g\) 与 \(h=g^a\)，求 \(a\)，称为离散对数问题（DLP）。

在小群中，枚举即可破解；在经过审计的大素数阶群中，未发现已知的高效通用算法。安全性不是数学定理“绝对不可逆”，而是参数、群选择和当前计算能力下的困难性假设。

## 可运行实验：看见一个小循环群

```python
from projects.crypto_toybox.finite_group import (
    discrete_log_toy,
    multiplicative_order,
    primitive_generators,
    subgroup_elements,
)

p = 23
assert multiplicative_order(2, p) == 11
assert len(subgroup_elements(2, p)) == 11  # 一个真子群
generator = primitive_generators(p)[0]
assert set(subgroup_elements(generator, p)) == set(range(1, p))

# 小群中可直接枚举；模块明确限制在 p <= 1000。
assert discrete_log_toy(generator, pow(generator, 7, p), p) == 7
```

该程序在教学规模枚举阶、生成元与离散对数，且拒绝复合模数和超过 1000 的枚举请求：它的作用正是让读者观察小群为何不安全，而不是生成参数或实现密钥交换。真实参数应由成熟协议/库固定选择，并使用密码学安全随机数。

## Diffie–Hellman 如何使用这些结构

公开 \(p,g\)，Alice 取秘密 \(a\)，发送 \(A=g^a\)；Bob 取秘密 \(b\)，发送 \(B=g^b\)。交换律使

\[
B^a=(g^b)^a=g^{ab}=(g^a)^b=A^b.
\]

观察者看见 \(g,A,B\)，但要得到共享值需要解决 CDH/DDH 等明确假设，而不仅是笼统地“猜指数”。完整协议还需要认证，否则中间人可分别与双方协商不同密钥。

## 工程边界与误区

- **素数模数不等于安全参数。** 小素数或可分解的 \(p-1\) 可能允许快速攻击；必须选标准群与大素数阶子群。
- **不验证对方公钥。** 恶意元素可能落在小子群，借多次交互泄漏私钥模小因子的值。
- **把教学 `pow` 当密码系统。** 它不提供密钥生成、常量时间、认证、KDF 或密钥生命周期管理。
- **把 DLP、CDH、DDH 混为一谈。** 它们是相关但不同的困难性假设，协议证明依赖的具体假设必须写明。
- **误以为椭圆曲线只是换了公式。** 它同样使用群，但元素是曲线点、运算是点加法，参数验证和小子群防护仍不可省略。

## 练习

2. 求模 15 下可逆元素集合，解释为什么 3 没有乘法逆元。
3. 修改 `powers`，输出 \(p=23\) 下每个元素的阶；哪些元素是生成元？
