# 密码学与数论深度版路线

## 主线

密码学深度版同时回答两个问题：数学原语为什么正确，以及一个“数学正确”的玩具为什么仍不能保护真实数据。每篇必须将安全假设、攻击面和生产边界写入正文。

## 分层与顺序

| 层级 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 整除、贝祖等式、最大公约数、模运算 | 既有文章待深化 |
| 1 | 模逆元、快速幂、CRT、素数与群论直觉 | 前三项已深化；素数与群论直觉待补齐 |
| 2 | RSA 正确性、Diffie–Hellman、概率性素性测试 | [RSA](/number-theory-crypto/rsa) 已深化 |
| 3 | 填充、侧信道、哈希/MAC、密码存储、椭圆曲线预备 | 玩具箱与后续文章 |

## 项目连接

[密码学玩具箱](/projects/crypto-toybox)只验证模幂、模逆元和小参数 RSA 的数学连接。后续扩展包括：演示裸 RSA 的确定性、比较错误密码存储与慢哈希、记录攻击前提；不实现或发布任何真实加密替代品。

## 练习

1. 用扩展欧几里得验证 $ed\equiv1\pmod{\varphi(n)}$。
2. 解释为何快速幂的分支模式可能泄漏指数位。
3. 设计一个裸 RSA 的确定性演示，但不得对真实数据使用。
4. 比较“密码哈希”与“通用哈希”在盐、成本和攻击模型上的不同。
