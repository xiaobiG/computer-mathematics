# 条件数：问题对误差有多敏感

即使算法完美，输入的一点点误差也可能让输出大幅变化。这是**病态问题**，不是实现失误。条件数衡量相对输入误差可能被放大的程度。

对于可逆矩阵，常见范数下：

$$\kappa(A)=\lVert A\rVert\lVert A^{-1}\rVert$$

当 $\kappa(A)$ 很大，线性系统的解对数据噪声敏感。两个几乎平行的方程直线，其交点就很不稳定。

## 条件与稳定的区别

- **条件数**：问题本身是否敏感；
- **稳定性**：算法是否引入不必要的额外误差。

稳定算法不能修复一个本质病态的问题，但能避免把可控的问题算坏。

## 练习

构造两条斜率非常接近的直线，轻微扰动常数项并观察交点的巨大变化。
