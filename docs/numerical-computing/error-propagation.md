# 绝对误差、相对误差与消去：误差如何在计算中放大

## 学习目标

读完后，你能区分绝对误差和相对误差；推导两个近似量相乘的误差界；用相减条件数解释灾难性消去；并能在零参考值、精确相减和非有限输入时选择明确的程序契约。

## 从“同样差 1”开始

测量值从 $1000$ 变成 $1001$，与从 $0.001$ 变成 $1.001$ 的绝对误差都为 $1$，但前者通常可忽略，后者几乎完全失真。程序若只报告一个误差数而不报告尺度，就无法判断结果是否可用。

## 定义与乘法传播

对真值 $x$ 与近似值 $\hat x$，绝对误差为

$$\Delta x=|\hat x-x|,$$

而 $x\ne0$ 时相对误差为

$$\delta x=\frac{|\hat x-x|}{|x|}.$$

相对误差在 $x=0$ 处没有定义；这不是代码应偷偷替换成零的地方，应转回绝对误差或依赖问题语境的混合容差。

设两个近似满足 $\hat a=a(1+e_a)$、$\hat b=b(1+e_b)$，且 $|e_a|\le\varepsilon_a$、$|e_b|\le\varepsilon_b$。相乘得到

$$\hat a\hat b=ab(1+e_a)(1+e_b),$$

所以相对误差至多

$$\varepsilon_a+\varepsilon_b+\varepsilon_a\varepsilon_b=(1+\varepsilon_a)(1+\varepsilon_b)-1.$$

一阶近似常写成 $\varepsilon_a+\varepsilon_b$，但实验会保留二阶项，避免把“近似”误写成精确等式。

## 为什么相减特别危险

函数 $f(a,b)=a-b$ 对输入相对扰动的相对条件数可写为

$$\kappa_{-}(a,b)=\frac{|a|+|b|}{|a-b|}.$$

当 $a,b$ 接近时，分母很小，即使输入各自只有少量相对误差，也会在差值中被巨大放大。若 $a=b$，目标值为零，条件数趋于无穷：这正是“相近数相减”需要代数改写或更高精度的原因。

## 正确性与工程边界

乘法界来自上面的恒等式和三角不等式；测试构造两个分别为 1% 和 2% 的输入扰动，验证真实乘积相对误差不超过 $3.02\%$ 的界。相减条件数只描述**问题**对相对输入扰动的放大，并不表示某个具体实现一定不稳定；稳定算法也无法让一个本质病态的相减问题变得良态。

- **零附近**：相对误差会爆炸或无定义，使用有物理单位的绝对容差。
- **取消误差**：先检查公式能否有理化、重排或改为稳定特殊函数；不要只增加打印精度。
- **界不是估计值**：最坏情况误差界可能很保守，仍应报告实际残差或和高精度基准的差异。
- **浮点舍入以外的误差**：传感器、离散化、模型错设和随机抽样都可能主导；不能把它们都归因于 IEEE 754。

## 练习

1. **基础**：比较真值 $2$ 的近似 $2.01$ 与真值 $0.002$ 的近似 $0.012$ 的绝对、相对误差。
2. **推导**：从 $(1+e_a)(1+e_b)$ 展开乘法相对误差，并给出三项上界。
3. **编码**：为三项乘积写误差界，并与随机的小扰动样本核对其上界性质。
4. **开放**：为 $\sqrt{x+1}-\sqrt{x}$ 在 $x\gg1$ 的计算写出相减条件分析和有理化改写，并说明仍需报告哪些误差证据。
