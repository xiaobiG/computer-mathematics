# 数值插值：差商、牛顿形式与外推为何危险

## 学习目标

读完后，你能用差商构造牛顿插值多项式；解释它为何精确通过给定节点；实现嵌套求值；并判断高阶、等距节点与外推何时会让插值失去可靠性。

## 从一个计算问题开始

程序常只知道传感器在少数时刻的读数，却需要估计中间时刻的值。简单连线可能太粗糙，直接把数据塞进高次幂基底又会带来病态的 Vandermonde 方程。牛顿形式逐个加入节点：已有多项式无需重算，新增系数由差商给出。

## 定义与推导

给定互异节点 $(x_i,y_i)$，次数至多 $n$ 的插值多项式在所有节点满足 $p_n(x_i)=y_i$，且唯一。牛顿形式为

$$p_n(x)=c_0+c_1(x-x_0)+c_2(x-x_0)(x-x_1)+\cdots+c_n\prod_{j=0}^{n-1}(x-x_j).$$

令零阶差商 $f[x_i]=y_i$，递推为

$$f[x_i,\ldots,x_{i+k}]=\frac{f[x_{i+1},\ldots,x_{i+k}]-f[x_i,\ldots,x_{i+k-1}]}{x_{i+k}-x_i}.$$

则 $c_k=f[x_0,\ldots,x_k]$。每个新项含有先前所有 $(x-x_j)$，所以在旧节点自动为零；这说明加入节点不会破坏已满足的插值条件，也给出唯一性的构造性证明。

## 手算例子

对 $(-1,2),(0,1),(2,5)$，一阶差商为 $-1,2$，二阶差商为 $1$，因此

$$p(x)=2-(x+1)+(x+1)x=x^2+1.$$

它在三个节点精确相等，并在 $x=3$ 给出 10。实现时采用嵌套乘法 $c_0+(x-x_0)[c_1+(x-x_1)(c_2+\cdots)]$，避免反复构造幂和乘积。

## 可运行实现

```python
from projects.floating_point_museum.interpolation import divided_differences, evaluate_newton

nodes = [-1.0, 0.0, 2.0]
coefficients = divided_differences(nodes, [2.0, 1.0, 5.0])
assert evaluate_newton(nodes, coefficients, 3.0) == 10.0
```

运行 `python -m unittest projects.floating_point_museum.test_interpolation`。测试验证二次函数在节点内外的精确复原，以及重复节点、长度不匹配和系数维度错误会被拒绝。构造差商表为 $O(n^2)$ 时间、$O(n)$ 额外空间；一次嵌套求值为 $O(n)$。

## 误差、正确性与边界

若 $f$ 有 $n+1$ 阶导数，余项为

$$f(x)-p_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^{n}(x-x_i)$$

其中 $\xi$ 位于节点与 $x$ 的区间内。它解释两件事：插值在节点附近往往更可信；区间外的乘积会迅速增长，外推没有同样的保障。对宽区间上的等距高阶节点，Runge 现象会在端点振荡，即使节点值全部精确。生产代码常采用低阶分段插值、样条或 Chebyshev 节点，而不是盲目提高全局次数。

## 常见误区

- **“通过所有数据点就等于预测准确”**：插值只保证节点拟合，不保证噪声外的泛化。
- **“高阶一定更精确”**：Runge 振荡和舍入误差可能更坏。
- **“外推只是插值更远一点”**：余项乘积可能急剧放大。
- **“节点可重复”**：普通差商分母为零；重复节点需要 Hermite 插值及导数信息。

## 练习

1. **基础**：为三个节点列出一阶和二阶差商。
2. **推导**：证明新牛顿基函数在所有旧节点为零。
3. **编码**：每加入一个节点输出当前插值多项式在全部旧节点的残差。
4. **开放**：比较等距节点和 Chebyshev 节点对 $1/(1+25x^2)$ 的高阶插值，记录端点最大误差。

## 练习答案提示

1. 一阶差商是相邻函数值差除以节点差，二阶差商再对一阶差商做同样操作；先检查节点互异。
2. 第 $k$ 个牛顿基含因子 $\prod_{i<k}(x-x_i)$，在任一旧节点至少有一个因子为零，所以新项不改变已拟合值。
3. 每次扩展后逐一代回所有已有节点并记录最大残差；节点重复、长度不符和高阶外推都应有独立失败/诊断测试。
4. 用同一节点数和评估网格比较端点最大误差；Chebyshev 节点在端点更密，常抑制 Runge 振荡，但不是噪声数据的万能解法。
