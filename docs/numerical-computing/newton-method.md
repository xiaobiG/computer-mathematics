# 牛顿法：用切线快速逼近方程的根

## 学习目标

读完后，你能从一阶泰勒展开推导牛顿迭代；说明简单根附近为何二次收敛；实现有迭代上限、残差检查和区间保护的求根器；并能识别导数过小、初值过远和多重根造成的失败。

## 从一个“很快但不可靠”的需求开始

要解 $\cos x-x=0$，二分法稳定但每一步只把区间减半。牛顿法通常几步就给出很多正确数字，因而常被直接写进优化器、物理仿真和隐式方程求解器。但“通常很快”不是“总会收敛”：对 $f(x)=x^3-2x+2$，从 $x_0=0$ 出发会在 $0$ 与 $1$ 间来回跳。

数值算法的目标不是只写出更新公式，而是定义何时相信它、何时停止、何时回退。

## 直觉：用局部直线代替曲线

当前猜测为 $x_k$ 时，函数附近的一阶模型为

$$f(x)\approx f(x_k)+f'(x_k)(x-x_k).$$

把这条切线与横轴的交点作为下一个猜测，令右侧为零，得到

$$x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}.$$

分子是当前残差，分母把“函数单位”换成“自变量单位”。斜率很小时，同样的残差会被放大成危险的大步长。

## 严格定义与局部收敛推导

设 $r$ 是根，$f(r)=0$，且 $f'(r)\ne0$。记误差 $e_k=x_k-r$。在 $r$ 处二阶泰勒展开：

$$f(x_k)=f'(r)e_k+\frac{f''(r)}{2}e_k^2+O(e_k^3),$$

$$f'(x_k)=f'(r)+f''(r)e_k+O(e_k^2).$$

代入 $e_{k+1}=x_{k+1}-r=e_k-f(x_k)/f'(x_k)$，并在 $e_k$ 很小时展开比值，得到

$$e_{k+1}=\frac{f''(r)}{2f'(r)}e_k^2+O(e_k^3).$$

主项是 $e_k^2$，因此误差足够小时，正确位数大致每步翻倍，这称为**二次收敛**。前提很强：根是简单根、函数够光滑、初值已在收敛盆内，且浮点误差还没有主导计算。

若根重数为 $m>1$，例如 $f(x)=(x-r)^m$，普通牛顿法只线性收敛：$e_{k+1}\approx(1-1/m)e_k$。已知重数时可改用 $x_{k+1}=x_k-m f(x_k)/f'(x_k)$。

## 算法：残差、步长与区间缺一不可

停止时只看 $|x_{k+1}-x_k|$ 不够：迭代可能因导数极大而几乎不动，但 $f(x)$ 仍很大。只看 $|f(x)|$ 也不够：病态问题里很小的残差未必对应很小的自变量误差。因此同时检查残差和相对步长，并设置最大迭代次数。

```text
给定连续函数 f、导数 f'、含根区间 [a,b] 和初值 x
重复至多 max_steps 次：
  若 |f(x)| <= residual_tol：返回 x
  尝试 y = x - f(x) / f'(x)
  若导数过小，或 y 不在 (a,b)：令 y = (a+b)/2  （二分回退）
  用 f(y) 的符号保留仍含根的半区间
  若 |y-x| <= step_tol * max(1, |y|) 且 |f(y)| 足够小：返回 y
  x = y
报错：在上限内未满足停止条件
```

二分回退牺牲局部速度，换来“只要 $f(a)f(b)<0$ 且连续就不丢根”的全局保障。它是工程中比纯牛顿法更常用的混合策略。

## 可运行实现：受保护的牛顿法

```python
from projects.floating_point_museum.root_finding import safeguarded_newton_trace

root, events = safeguarded_newton_trace(
    lambda x: x * x - 2.0, lambda x: 2.0 * x,
    0.0, 2.0, initial=1.0,
)
assert abs(root * root - 2.0) <= 1e-12
assert all(event.left_value * event.right_value <= 0.0 for event in events)
```

运行 `python -m unittest projects.floating_point_museum.test_root_finding`。`safeguarded_newton_trace` 返回每一步的方法、候选值、残差和更新后的区间端点/函数值。测试不只检查 $\sqrt2$ 的近似值，还验证每个事件仍保留符号变化；对 $x^3-2x+2$ 从 $0$ 出发，首次越界的牛顿建议会被替换为二分步。每轮计算量为 $O(1)$（不计函数本身），总成本为 $O(k)$ 次函数/导数评估。局部二次收敛能显著减小 $k$，但昂贵导数、自动微分图和区间回退都会改变实际成本。

## 正确性与可验证实验

对代码的可验证断言不是“结果看起来像 $\sqrt2$”，而是：返回值仍在原区间；残差足够小；且每次区间都保持符号变化。对 $f(x)=x^2-2$，可记录区间长度；发生二分时它至少减半，发生安全的牛顿步时通常更快缩小。

对于多根、没有符号变化的偶重根，区间法的前提不成立。例如 $f(x)=(x-1)^2$ 在根两侧都非负；这并非程序 bug，而是该全局保证的边界。需要用最小化 $|f|$、导数根或问题领域的其他信息来定位它。

## 失败案例与工程边界

- **两点循环**：$x^3-2x+2$ 从 $0$ 出发产生 $0\to1\to0$。残差不降时必须拒绝盲目迭代。
- **导数接近零**：$f(x)=x^{1/3}$ 在 $0$ 附近导数发散，数值差分导数尤其不可靠。
- **多重根**：$(x-1)^2$ 让普通牛顿失去二次收敛，停止准则须避免把慢收敛误判为失败或成功。
- **有限精度平台**：当更新小于一个 ulp，$x_{k+1}=x_k$ 即使残差未达目标也会停滞。返回状态应区分“收敛”“停滞”“迭代耗尽”。

## 常见误区

1. “牛顿法总比二分法好。”错误：二分有明确全局条件，牛顿主要是局部方法。
2. “步长变小就已找到根。”错误：还必须检查残差和问题尺度。
3. “导数可以总用极小差分步长。”错误：步长过小会让相减消去和舍入误差吞没导数信号。
4. “小残差等于小误差。”错误：当 $f'(r)$ 很小时，问题本身可能病态。

## 练习

1. **基础题**：从 $f(x)=x^2-a$ 推导计算 $\sqrt a$ 的牛顿迭代，并手算两步 $a=2,x_0=1$。
2. **推导题**：对 $f(x)=(x-r)^m$ 直接计算 $e_{k+1}/e_k$，说明为何普通迭代仅线性收敛。
3. **编码题**：为 `safeguarded_newton` 返回迭代轨迹和状态码；用它展示纯牛顿法在 $x^3-2x+2$ 的循环，以及混合方法如何避免循环。
4. **开放题**：一个隐式物理方程每次计算 $f$ 要 5 秒、计算 $f'$ 要 30 秒。比较解析导数、割线法、自动微分和混合策略，说明你将如何测量并选择方案。
