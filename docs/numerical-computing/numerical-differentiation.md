# 数值微分与步长选择：为什么 h 不是越小越好

## 学习目标

读完后，你能从泰勒展开推导前向、中心差分的误差阶；解释相减消去如何产生 $O(u/h)$ 误差；实现带输入检查的中心差分实验；并知道何时应改用解析导数、自动微分或复步长法。

## 从“把 h 调到最小”失败开始

想在 $x=1$ 求 $\sin x$ 的导数，写下 `(sin(x+h)-sin(x))/h` 后，人们常把 $h$ 设成 `1e-20`。在双精度中，$1+h$ 甚至可能与 $1$ 完全相同，或两个近似相等的函数值相减后有效数字消失。结果不是更精确，而可能得到零或随机噪声。

有限差分有两种相反的误差来源：步长大时局部线性模型太粗糙；步长小时浮点噪声被除以 $h$ 放大。最佳步长位于两者平衡处。

## 从泰勒展开推导误差阶

在 $x$ 处展开：

$$f(x+h)=f(x)+hf'(x)+\frac{h^2}{2}f''(x)+O(h^3).$$

前向差分

$$D_f(h)=\frac{f(x+h)-f(x)}{h}=f'(x)+\frac h2f''(x)+O(h^2)$$

的截断误差是 $O(h)$。再展开 $f(x-h)$ 并相减，偶次项抵消：

$$D_c(h)=\frac{f(x+h)-f(x-h)}{2h}=f'(x)+\frac{h^2}{6}f'''(x)+O(h^4).$$

因此中心差分的截断误差为 $O(h^2)$，在函数值评估相近成本下通常更好。

## 舍入误差为何反向增长

设每次函数值有相对误差约 $u$（双精度 $u\approx 2^{-53}$）。差分分子相减时绝对噪声约与 $u|f(x)|$ 同量级，除以 $h$ 后约为 $O(u|f(x)|/h)$。中心差分的总误差可以粗略写成

$$E(h)\approx C_1h^2+C_2\frac{u}{h}.$$

平衡两项得到 $h\asymp u^{1/3}$（常数依赖函数与尺度）。前向差分则约为 $C_1h+C_2u/h$，最佳数量级是 $u^{1/2}$。这些不是可盲抄的常数：若 $x$ 或函数尺度很大，应按问题缩放；若函数有噪声，噪声项可能完全主导。

```python
assert report["certificate"]["small_steps_rebound_after_best"]

```

运行 `python -m unittest projects.floating_point_museum.test_differentiation`。扫描报告保留每个 $h=10^{-k}$ 的估计和绝对误差，并检查粗步长的相邻误差比是否处于二阶趋势的合理范围、最小步长之后是否发生误差反弹。输出通常先随 $h$ 减小而变好，随后因舍入误差而变坏，形成 U 形曲线。不要把某次最低点当作普遍最优值；它随平台、函数、输入和噪声改变。

## 算法选择与验证

有限差分的计算成本是每个方向两次函数调用；多维函数的坐标差分需要 $O(n)$ 次调用来近似一个梯度，Jacobian 则更多。验证时应在有解析导数的测试函数上比较结果，并做两类测试：

- 缩小 $h$ 时，在截断误差主导区观察理论阶数；
- 进入极小 $h$ 后观察误差反弹或结果停滞。

若程序内部可微且框架支持，自动微分应用链式法则，避免有限差分相减消去；解析导数通常最快最可靠。复步长法 $\operatorname{Im}(f(x+ih))/h$ 可避免实数相减，但要求函数支持复数且没有不可解析分支。

## 失败案例与工程边界

- **不可微点**：$|x|$ 在零处没有导数；中心差分给出的数值不是数学导数。
- **有噪声的函数评估**：模拟器或随机训练损失的噪声会被 $1/h$ 放大；需重复采样、平滑或随机近似。
- **域边界**：$\log x$ 在 $x$ 接近零时的双侧点可能越界；改用单侧公式或变量变换。
- **高维成本**：用差分检查一个深度网络的所有参数非常昂贵；只抽样方向或参数子集进行梯度检查。

## 常见误区

1. “h 越小，泰勒近似越准，所以结果越准。”错误：舍入误差项随 $1/h$ 增长。
2. “中心差分总是安全。”错误：它仍要求两侧都在定义域、函数评估稳定。
3. “数值梯度可替代自动微分。”错误：高维时成本和噪声都更差；它更适合验证。
4. “差分误差小就证明实现无误。”错误：测试点、尺度和容差可能掩盖符号或广播错误。

## 练习

1. **基础题**：由泰勒展开推导中心差分中二阶项为何抵消。
2. **推导题**：最小化 $C_1h^2+C_2u/h$，推得中心差分最优步长的数量级。
3. **编码题**：用 `scan_steps` 对 $f(x)=e^x$ 与 $f(x)=\sin x$ 作表，估计误差最小时的 $h$ 并解释差异。
4. **开放题**：为一个含随机噪声的仿真器设计梯度估计方案，比较有限差分、共同随机数、SPSA 与自动微分的适用条件。

## 练习答案提示

1. 分别展开 $f(x+h),f(x-h)$ 并相减，偶次项抵消；除以 $2h$ 后首个截断项为 $O(h^2)$。
2. 对 $2C_1h-C_2u/h^2=0$ 求解，得到 $h$ 的量级为 $u^{1/3}$；常数取决于高阶导数和舍入模型。
3. 用解析导数作参考，扫对数尺度的 $h$；误差曲线通常先下降后上升，不同函数的高阶导数与尺度使最优点不同。
4. 噪声下可用共同随机数降低两次评估差的方差，SPSA 适合高维方向采样，自动微分需可微且能访问计算图；报告偏差、方差和调用预算。

## 延伸

数值微分与[牛顿法](/numerical-computing/newton-method)直接相连：不稳健的导数会让牛顿步失控。继续学习[数值积分](/numerical-computing/numerical-integration)可看到同样的“截断误差与舍入误差权衡”；若要在机器学习中安全验证梯度，研究方向导数与自动微分中的 Jacobian-vector product。
