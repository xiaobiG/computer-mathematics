# 数值微分与步长选择

导数可用有限差分近似：

$$f'(x)\approx\frac{f(x+h)-f(x)}{h}$$

$h$ 变小时，泰勒展开带来的截断误差变小；但两个接近数相减会产生消去误差，随后再除以很小的 $h$ 会放大浮点误差。因此 $h$ 并非越小越好。

中心差分：

$$f'(x)\approx\frac{f(x+h)-f(x-h)}{2h}$$

通常有更小的截断误差，但仍需避免过小步长。

```python
def central_difference(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)
```

## 工程连接

数值微分用于无解析导数的模拟与优化。若可获得自动微分或解析导数，通常更可靠；有限差分适合作为验证工具。

对 $f(x)=\sin x$ 在 $x=1$ 处用不同 $h$ 计算导数，画出误差随 $h$ 的变化，找出最小误差附近。
