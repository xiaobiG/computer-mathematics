# 条件概率与贝叶斯更新

## 先问一个问题

分类器报告“邮件像垃圾邮件”，是否意味着它几乎肯定是垃圾邮件？不一定；还要知道垃圾邮件原本有多常见，以及该特征对正常邮件有多容易误报。

## 条件概率

已知事件 $B$ 发生时，$A$ 发生的概率是：

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}$$

贝叶斯公式将观察方向反过来：

$$P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}$$

其中 $P(A)$ 是先验，$P(B\mid A)$ 是似然，$P(A\mid B)$ 是看到证据后的后验。

## 一个数字例子

假设 1% 的邮件是垃圾邮件；某关键词在垃圾邮件中出现的概率为 90%，在正常邮件中为 5%。看到关键词后：

$$P(垃圾\mid 关键词)=\frac{0.9\times0.01}{0.9\times0.01+0.05\times0.99}\approx15.4\%$$

关键词很敏感，却不足以单独定罪，因为正常邮件数量远多于垃圾邮件。

## 代码实验

```python
prior_spam = 0.01
likelihood = 0.90
false_positive = 0.05

posterior = likelihood * prior_spam / (
    likelihood * prior_spam + false_positive * (1 - prior_spam)
)
print(f'{posterior:.1%}')  # 15.4%
```

## 机器学习连接

朴素贝叶斯会把多个特征的似然相乘，并假设在类别已知时这些特征相互独立。这一假设通常不完全真实，但模型仍可能实用、快速且易解释。

## 练习

将先验改为 20%，比较后验如何变化；再思考为什么医疗筛查和垃圾邮件过滤都容易出现“低基率”误解。
