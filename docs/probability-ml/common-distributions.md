# 常见分布如何建模现实

分布不是数据标签，而是对生成机制的假设。

| 分布 | 典型问题 | 关键参数 |
| --- | --- | --- |
| 伯努利 | 一次成功或失败 | 成功概率 $p$ |
| 二项 | 固定次数中的成功数 | 次数 $n$、概率 $p$ |
| 泊松 | 固定区间的事件数量 | 平均速率 $\lambda$ |
| 指数 | 下一次事件还需等待多久 | 速率 $\lambda$ |
| 正态 | 大量微小因素叠加的误差 | 均值 $\mu$、标准差 $\sigma$ |

## 生成机制比外形重要

泊松过程假设独立、均匀的到达；指数分布具有无记忆性。正态分布常很有用，但不能因为直方图“大致钟形”就忽视偏态、厚尾或离散边界。

## 练习

为“网站一分钟内收到的请求数”“一枚硬币十次中的正面数”“一次测量误差”分别选择候选分布，并写出选择时依赖的假设。
