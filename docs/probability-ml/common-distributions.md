# 常见分布如何建模现实

## 学习目标

读完后，你能把“数据长得像什么”改写成可检验的生成假设；能从独立试验推出二项分布、从泊松过程推出指数等待时间；能用均值—方差关系和最小代码发现模型不适配。

## 从一个建模错误开始

“每分钟平均 8 个”不等于每分钟必有 8 个；钟形图也不自动允许正态。分布是生成机制：先分清一次试验、固定窗计数、等待时间或连续误差。

## 直觉与定义：五种最常用的生成机制

| 分布 | 随机变量 | 生成假设 | 参数与均值方差 |
| --- | --- | --- |
| 伯努利 | 一次成败 $X\in\{0,1\}$ | 一次试验成功概率固定 | $p$；$E[X]=p,\mathrm{Var}(X)=p(1-p)$ |
| 二项 | $n$ 次中的成功数 | 独立同分布伯努利试验 | $n,p$；$np,np(1-p)$ |
| 泊松 | 时间/空间窗内的事件数 | 独立、均匀、稀疏到达 | $\lambda$；$\lambda,\lambda$ |
| 指数 | 下一事件等待时间 | 泊松过程的相邻到达间隔 | $\lambda$；$1/\lambda,1/\lambda^2$ |
| 正态 | 连续测量误差或总和 | 许多小影响相加且无主导项 | $\mu,\sigma$；$\mu,\sigma^2$ |

这里的 $\lambda$ 要写清单位：若它是“每分钟 8 个”，则一分钟内计数用 $\mathrm{Poisson}(8)$；等待时间的单位是分钟，均值是 $1/8$ 分钟。

## 从伯努利到二项：组合数为何出现

令第 $i$ 次试验的成功指示变量为 $X_i\sim\mathrm{Bernoulli}(p)$，总成功数是

$$S=X_1+\cdots+X_n.$$

事件 $S=k$ 意味着恰有 $k$ 个位置成功。一种指定的成功/失败排列概率为 $p^k(1-p)^{n-k}$；这样的排列有 $\binom{n}{k}$ 种，故

$$P(S=k)=\binom{n}{k}p^k(1-p)^{n-k},\quad k=0,\ldots,n.$$

期望无需展开这个求和：线性性给出 $E[S]=\sum_i E[X_i]=np$。独立性使协方差为零，因此 $\mathrm{Var}(S)=np(1-p)$。这也解释了为什么二项模型不适用于“抽样不放回”：此时 $X_i$ 彼此相关。

## 泊松计数与指数等待时间

把长度为 $t$ 的时间窗切为许多很短的小段。若每段最多一个事件、事件机会近似独立，且总平均到达数趋于 $\lambda t$，二项分布在“小概率、大次数”极限下成为

$$P(N(t)=k)=e^{-\lambda t}\frac{(\lambda t)^k}{k!}.$$

“等待超过 $t$”等价于前 $t$ 时间内一个事件也没有：

$$P(T>t)=P(N(t)=0)=e^{-\lambda t}.$$

所以 $T$ 的分布函数为 $F_T(t)=1-e^{-\lambda t}$，密度为 $f_T(t)=\lambda e^{-\lambda t}$。并且

$$P(T>s+t\mid T>s)=\frac{e^{-\lambda(s+t)}}{e^{-\lambda s}}=e^{-\lambda t}.$$

这就是无记忆性：已经等了多久不改变剩余等待的分布。人类回复、服务器排队和促销流量通常不满足它。

## 正态分布不是“万能钟形”

独立、方差有限且无单项主导的小影响之和才近似正态；范围、偏态、厚尾与相关性都要检查。金额、时长和计数常需其他模型。

## 可运行实验：用统计量先筛掉错误模型

泊松变量的均值与方差应相近；二项变量的方差不超过均值；独立泊松过程的相邻等待时间应近似指数。下面的函数先做廉价诊断，而非宣称“证明了分布”。

```python
from projects.naive_bayes_spam.count_diagnostics import (
    count_diagnostics,
    count_diagnostics_certificate,
)

report = count_diagnostics([0, 0, 0, 10, 10, 10])
assert report.variance_to_mean > 1.0
assert report.zero_fraction > report.poisson_zero_fraction_at_mean
assert count_diagnostics_certificate([0, 0, 0, 10, 10, 10], report)["valid"]
```

报告以 $e^{-\lambda}$ 作零值基线，证书重算均值、方差与离散度。偏离是时段混合、激发或分组速率不同的信号，不是正式拒绝检验；仍须检查独立性和留出预测。

## 右截尾：删失时间不是“短事件时间”

对每人只观察 $X_i=\min(T_i,C_i)$ 与事件标记 $\delta_i=I(T_i\le C_i)$。当 $\delta_i=0$，我们只知道事件晚于 $X_i$，不能把 $X_i$ 当作事件时间或直接丢弃。于每个事件时刻 $t_j$，令 $Y_j$ 为尚未事件、未在更早时刻删失的人数，$d_j$ 为事件数，则

$$
\widehat S(t)=\prod_{t_j\le t}\left(1-\frac{d_j}{Y_j}\right),
\qquad \widehat{\mathrm{RMST}}(\tau)=\int_0^\tau\widehat S(t)\,dt.
$$

```python
from projects.naive_bayes_spam.right_censoring import right_censoring_report

report = right_censoring_report([("a", 1, True), ("b", 2, False), ("c", 3, True), ("d", 4, False)], 4)
assert report.survival_at_horizon == 0.375
assert report.restricted_mean_survival_time == 2.875
```

报告逐时刻绑定风险集、事件、删失与阶梯生存率；证书会拒绝改写它们。它只在**独立删失已声明**时解释为生存估计，这一前提不能从本表验证；不处理左截断、区间删失、竞争风险、协变量、因果比较或自动决策。[Kaplan–Meier 方法的风险集说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC8478547/)解释了右截尾和该前提。

## 算法视角：模型选择的最小流程

观测单位 → 支持集与机制假设 → 参数/诊断 → 时间、分组与极端值检查。复杂模型未必更好；高成本场景应加留出预测或似然审计。

## 失败案例与工程边界

- **把非独立日志当作二项试验**：同一用户连续点击会让方差上升，置信区间过窄。
- **泊松速率随时间变化**：午间与夜间混在一起会产生过度离散；可按时段分层，或使用非齐次泊松过程。
- **正态尾部被低估**：延迟和损失常有厚尾。用平均值加三倍标准差做容量规划可能漏掉真正的峰值。
- **小样本“拟合得很好”**：直方图的形状容易偶然相似。保留新时间段做预测检查，优先问模型能否预测而非能否画出平滑曲线。

## 常见误区

1. “泊松的参数就是每次实验成功概率。”错误：泊松的 $\lambda$ 是一个窗内的平均计数；伯努利的 $p$ 才是单次成功概率。
2. “指数分布的无记忆性适合所有等待。”错误：它是恒定、独立到达的强假设。
3. “均值方差相等就证明是泊松。”错误：这是必要诊断而非充分证明；还需检查取值、独立性与预测表现。
4. “正态近似能让离散和负数问题消失。”错误：近似应检查范围；小计数和尾概率尤其危险。

## 练习

1. **基础题**：一枚硬币抛 $10$ 次，正面概率为 $0.3$。写出恰有 $4$ 个正面的二项概率及其期望、方差。
2. **推导题**：从 $P(T>t)=e^{-\lambda t}$ 推导指数密度，并验证它的无记忆性。
3. **编码题**：篡改 `count_diagnostics` 报告的零值基线，确认其证书拒绝；再加入分时段统计。构造一组“白天速率 10、夜间速率 1”的合并计数，解释为何整体并非好的单泊松模型。
4. **开放题**：为“商品退货所需天数”提出两个候选分布和至少三条可检验假设；说明你会怎样处理未完成退货的截尾数据。

## 练习答案提示

1. 使用 $\binom{10}{4}0.3^4(0.7)^6$；二项分布的期望为 $np$、方差为 $np(1-p)$，先确认试验独立且 $p$ 固定。
2. 由生存函数取负导数得密度 $\lambda e^{-\lambda t}$；条件概率 $P(T>s+t\mid T>s)$ 中指数项相除即可验证无记忆性。
3. 先让证书从原计数重算均值、方差和 $e^{-\bar x}$；保留时段标签后分别估计均值/方差，再与合并数据比较。混合不同速率通常导致方差关系和预测尾部偏离单一泊松模型。
4. 明确候选的支持集、风险率或尾部形状、个体独立性等假设；未完成退货是右截尾，应记录观察窗口并使用生存分析/截尾似然而非当作普通完整样本。
