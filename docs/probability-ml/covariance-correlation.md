# 协方差、相关性与特征

协方差描述两个变量偏离各自均值时是否倾向于同向变化：

$$Cov(X,Y)=E[(X-E[X])(Y-E[Y])]$$

正值表示常同向，负值表示常反向。相关系数进一步标准化：

$$\rho_{X,Y}=\frac{Cov(X,Y)}{\sigma_X\sigma_Y}$$

它位于 $[-1,1]$，便于比较不同量纲的变量。

## 三个边界

- 相关性只描述线性共同变化，可能漏掉非线性关系；
- 相关不等于因果，混杂变量可能同时影响两者；
- 样本相关会波动，需结合样本量和不确定性解释。

协方差矩阵是 PCA、马氏距离和多元高斯模型的基础。

## 练习

构造 $Y=X^2$ 且 $X$ 在对称区间均匀取值的样本。解释为何两者关系很强但线性相关可能接近零。
