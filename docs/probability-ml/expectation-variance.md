# 期望、方差与不确定性

## 期望不是“最可能发生的值”

离散随机变量 $X$ 的期望是加权平均：

$$E[X]=\sum_xxP(X=x)$$

掷公平骰子的期望是 3.5，虽然单次永远不会掷出 3.5。它描述的是大量重复实验的平均水平。

## 方差衡量波动

$$Var(X)=E[(X-E[X])^2]$$

平方使正负偏离不互相抵消，并且更惩罚离均值很远的结果。标准差 $\sigma=\sqrt{Var(X)}$ 的单位与原变量相同，更便于解释。

```python
def mean(xs):
    return sum(xs) / len(xs)

def variance(xs):
    mu = mean(xs)
    return sum((x - mu) ** 2 for x in xs) / len(xs)
```

## 机器学习连接

预测误差可拆分为偏差、方差和不可约噪声。模型过于简单通常偏差高；模型对训练数据过分敏感通常方差高。交叉验证的价值，正是在有限样本下估计这种泛化不确定性。

## 练习

构造两组均值相同、方差明显不同的数据；解释哪一组的结果更稳定，以及为什么均值不足以描述风险。
