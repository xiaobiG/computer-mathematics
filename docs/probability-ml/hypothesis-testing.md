# 假设检验与 p 值：证据为何不等于结论

## 学习目标

读完后，你能写出 A/B 测试的零假设、备择假设和统计量；精确解释 p 值的条件语句；实现一个可运行的双侧置换检验；并区分统计显著性、效应量、置信区间与上线决策。

## 从“p = 0.03，所以有 97% 概率有效”开始

这句话错误地把 $P(\text{数据}\mid H_0)$ 倒成了 $P(H_0\mid\text{数据})$。若新按钮组的平均转化率高出旧组，而在“两个版本其实没有差异”的世界里，出现同样或更极端差异的概率为 $0.03$，我们说 p 值为 $0.03$。它没有告诉我们新按钮有效的后验概率，也没有告诉我们提升是否值得开发和维护。

## 定义：先固定规则，再看数据

设 $H_0$ 是零假设（例如两个版本的转化分布相同），$H_1$ 是备择假设。选择统计量 $T(D)$，如两组样本均值之差；观察值为 $t_{obs}$。双侧 p 值定义为

$$p=P_{H_0}\bigl(|T(D)|\ge |t_{obs}|\bigr).$$

拒绝规则是：在看数据前选定 $\alpha$，若 $p\le\alpha$ 则拒绝 $H_0$。若 $H_0$ 真且规则确实事先固定，长期重复实验的第一类错误率至多为 $\alpha$：

$$P_{H_0}(\text{拒绝 }H_0)\le\alpha.$$

这是关于**决策程序的长期频率**，不是单次实验中某个假设的概率。

## 推导直觉：为什么要比较“更极端”

若只计算“恰好看到 $t_{obs}$”的概率，连续统计量几乎总为零且结果依赖人为分箱。“不比观察到的更温和”将观测放在零假设下的尾部：尾部小表示数据与 $H_0$ 的典型输出不相称。

双侧检验将两端都算为意外，适合“只要有变化就关心”的预注册问题；若事后看到提升才改用单侧检验，会把错误率翻倍。方向、指标、最小样本量和停止时间应在试验前锁定。

## 算法：置换检验不必先假定正态

当 $H_0$ 认为组标签可交换时，把所有观测混合、随机重新分组，便模拟了零假设下统计量的分布。以“至少同样极端”的次数估计 p 值；加一修正避免得到不可能的零 p 值。

```python
from projects.naive_bayes_spam.permutation_test import two_sided_permutation_test

result = two_sided_permutation_test([0.0] * 6, [1.0] * 6, rounds=2_000, seed=8)
assert result.observed_difference == 1.0
assert result.p_value < 0.05
assert result.p_value >= 1 / 2_001  # 加一修正，不把有限模拟报成 p=0

same = two_sided_permutation_test([0, 1, 0], [0, 1, 0], rounds=200, seed=4)
assert same.p_value == 1.0
```

结果还保留 `extreme_permutations`、轮数和观察到的效应量，因此可复查分子、分母与模拟误差来源。时间复杂度约为 $O(Bn)$：$B$ 为置换次数、$n$ 为总样本量。随机种子使教学实验可复现，但真实分析应报告 $B$、随机源和数据排除规则。

## 正确性、效应量与区间

置换算法的正确性依赖可交换性：在 $H_0$ 下，任意保留组大小的标签重新分配都同样可能。若用户间相互影响、按地区分层却直接混合，或实验期间版本分配概率变化，这一前提失效。

还应报告绝对提升 $\hat\Delta=\bar x_T-\bar x_C$，而不是只有 p 值。一个极小但精确估计的提升可有很小 p 值却不值得上线；一个大但样本少的提升可能不显著，却值得继续收集数据。置信区间表达估计的不确定范围，业务最小可接受效果（MDE）表达价值阈值，两者不能由 p 值替代。

## 失败案例与工程边界

- **反复偷看**：每天算一次，显著即停止，会令“至少一次误报”的概率高于 $\alpha$。使用固定样本量、序贯检验或经校正的停止规则。
- **多指标/多版本**：二十个指标各按 $0.05$ 检验，几乎必然有偶然显著项。预先指定主指标，或做多重比较校正。
- **不独立的观测**：同一用户多次曝光不等于多个独立用户；按随机化单位聚合或使用分层/聚类方法。
- **选择性报告**：只保留“好看”的切片会夸大证据。记录全部实验、排除和分析分支。

## 常见误区

1. “p 值是零假设为真的概率。”错误：它条件在 $H_0$ 已真。
2. “$p>0.05$ 证明没有差异。”错误：可能只是功效不足；报告区间和 MDE。
3. “显著就应该上线。”错误：还需检查效应量、风险、长期留存与成本。
4. “置换检验没有假设。”错误：它仍假设零假设下标签可交换，且数据收集过程可信。

## 练习

1. **基础题**：为“新排序是否改变平均停留时间”写出 $H_0$、双侧 $H_1$、统计量和 $\alpha$。
2. **推导题**：若独立地进行 $20$ 个真实零假设检验，每个 $\alpha=0.05$，计算至少一次假阳性的概率 $1-0.95^{20}$，解释其含义。
3. **编码题**：给 `two_sided_permutation_test` 增加预先声明的单侧选项，并用固定种子验证两组相同数据的 p 值为 1。
4. **开放题**：为一次高风险医疗或金融实验设计预注册表：列出随机化单位、主指标、MDE、停止规则、排除条件和报告格式。

## 练习答案提示

1. 明确原假设为均值差为零，备择为不等于零；统计量和显著性水平必须在查看数据前固定，避免将业务叙述替代可检验命题。
2. 独立 20 次下“没有假阳性”概率为 $0.95^{20}$，其补集约为 0.64；这说明多重检验需预先控制，而非挑出一个显著结果。
3. 单侧方向必须预注册；相同组在所有置换下统计量相同，p 值应为 1，固定种子只让抽样近似可复现。
4. 预注册记录的是决策规则而非保证结果：指定随机化单位、主终点、最小效应、监测/停止、排除和完整报告，以避免反复查看和选择性分析。
