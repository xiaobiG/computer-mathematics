# 假设检验与 p 值

假设检验先设定零假设 $H_0$，例如“新版本没有提升转化率”，再选择统计量衡量观察数据与 $H_0$ 的偏离程度。

## p 值的正确含义

p 值是在 $H_0$ 为真时，得到当前或更极端数据的概率。它**不是**“零假设为真的概率”，也不是效果大小或实验价值。

设定显著性水平 $\alpha$ 后，若 $p<\alpha$，便拒绝 $H_0$。这控制的是长期第一类错误率：在没有真实效果时错误宣布有效。

## 实验中的常见误区

- 多次查看数据并在显著时停止，会抬高假阳性率；
- 样本量很大时，极小但无实际意义的差异也可能显著；
- 不显著不等于证明没有效果。

应同时报告效应量、置信区间、样本量与事先定义的决策规则。

## 练习

为 A/B 测试写出 $H_0$、$H_1$、主要指标和可接受的最小实际效应，再解释为何只看 p 值不够。
