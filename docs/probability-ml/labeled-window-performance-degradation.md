# 带标签窗口：审计分类性能与概率退化

## 学习目标

读完后，你能把输入漂移和带标签的模型评估区分开；为参考期与当前期定义可重放窗口；同时解释准确率、混淆矩阵、Brier 分数与对数损失；理解 Wilson 区间的作用与边界；并把指标信号限制为人工复核，而非自动重训或部署。

## 从一个计算问题开始

词袋垃圾邮件分类器的输入分布本周发生了变化，PSI 触发了告警。但三天后，人工标签才陆续返回。此时真正该问的是：**新窗口上的阈值分类变差了吗？模型给出的概率承诺变差了吗？**

这两个问题不能由输入频率单独回答。反过来，当前窗口的准确率更低也不能直接说明“某个新词导致了退化”。我们先把观察到的窗口、指标与政策阈值固定，再让报告只给出“是否需要复核”。

## 直觉与定义：标签到达后能回答什么

设参考带标签窗口为 $R=\{(p_i,y_i)\}_{i=1}^{n_R}$，当前窗口为 $C=\{(p_i,y_i)\}_{i=1}^{n_C}$；$p_i\in[0,1]$ 是预测为正类的概率，$y_i\in\{0,1\}$ 是之后到达的标签。以 $0.5$ 为分类阈值，预测为 $\hat y_i=\mathbb{1}[p_i\ge0.5]$。

准确率衡量阈值决定：

$$
\operatorname{accuracy}=\frac1n\sum_{i=1}^{n}\mathbb{1}[\hat y_i=y_i].
$$

它会丢掉概率的强弱。Brier 分数与对数损失分别保留平方误差和概率承诺：

$$
\operatorname{Brier}=\frac1n\sum_i(p_i-y_i)^2,
\qquad
\operatorname{LogLoss}=-\frac1n\sum_i\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].
$$

对数损失会严厉惩罚“接近 1 却押错”的预测。因此可能出现准确率几乎不变、但概率承诺明显变坏的窗口。实现会把概率裁剪到一个极小的正数附近，避免数学上的 $\log 0$；这只保证数值可算，不会抹去过度自信错误的高损失。

对每个窗口的准确率还报告 Wilson 区间。它描述有限样本下该比例估计的不确定性；两个区间是否重叠既不构成因果证明，也不是这里政策信号的唯一判据。

## 可运行报告与重放证书

窗口合同要求且只允许 `contract_version`、`probabilities` 与 `labels` 三个字段；两组数组必须等长、非空，概率必须在 $[0,1]$。报告把两个规范化窗口、阈值、指标、差值和 `automatic_action: "none"` 一起保存。

```python
report = compare(reference, current, 0.2, 0.3)
policy = report["policy"]

print(report["deltas"])
assert policy["automatic_action"] == "none"
assert verify(reference, current, report)
```

证书会从原始窗口和报告中的阈值独立重建整份报告。因此，改写准确率、损失、`needs_review` 或把行动写成自动重训，都会使证书失败。

## 信号、正确性与工程边界

本实验有两条政策信号：

$$
\Delta_{acc}=\operatorname{accuracy}(R)-\operatorname{accuracy}(C)
\ge \tau_{acc},\qquad
\Delta_{loss}=\operatorname{LogLoss}(C)-\operatorname{LogLoss}(R)
\ge \tau_{loss}.
$$

任意一条成立，`needs_review` 才为真。它的含义仅为：保留窗口、标签延迟、数据来源、阈值和报告版本，并由人检查数据采集、标注规范、群体覆盖、输入漂移与业务影响。

下面三个反例说明为什么不能越界：

- 输入 PSI 很高，但当前带标签性能稳定：可能是合法的新来源，不能断言模型失效。
- PSI 接近零，但当前对数损失上升：$P(X)$ 可不变而 $P(Y\mid X)$ 或标注口径发生变化。
- 一个 6 样本窗口损失显著变化：它值得复核，却不足以证明长期总体性能已改变。

报告不做自动重训、改变阈值、拦截流量或上线决策。真实系统还需要时间切分、标注质量审计、分层群体检查、错误成本与人为审批流程。

## 常见误区

- **“准确率下降就是概率校准变差。”** 不一定；准确率只看阈值两侧。
- **“对数损失变高就证明概念漂移。”** 不一定；采样、标签错误与数据管道变化都可能造成该现象。
- **“Wilson 区间给出显著性结论。”** 不对；这里它只呈现单个准确率估计的不确定性。
- **“触发复核等于必须重训。”** 不对；报告的自动行动明确为 `none`。

## 练习

1. **基础题**：若两个窗口的每个 $p_i,y_i$ 都相同，说明两窗口的四个差值为何都为零。
2. **推导题**：构造两个准确率相同的窗口，其中一个窗口对数损失更高，并解释原因。
3. **编码题**：为报告增加 `threshold` 字段并更新规范化、证书与测试；说明为什么它必须进入合同。
4. **开放题**：为一周标签延迟的分类器设计参考窗口、当前窗口与人工复核清单；写出一个不应被自动化的决策。

## 练习答案提示

1. 指标都是同一组有限求和或由其导出的量，故参考与当前相等时差值为零。
2. 保持预测标签不变，但把一个正确例的概率靠近 $0.5$，或把一个错误例的概率推近 0 或 1；后者会显著增加对数损失。
3. 阈值决定混淆矩阵与准确率；若证书不绑定它，攻击者可改阈值后仍伪称同一结论。
4. 记录时间范围、数据/标注版本、延迟、群体、输入漂移和业务错误成本；是否重训或部署必须由具备上下文的人决定。
