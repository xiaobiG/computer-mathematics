# 最大似然：从数据估计参数

## 从“模型可信度”开始

给定参数 $\theta$，数据 $x_1,\ldots,x_n$ 出现的概率或密度，作为 $\theta$ 的函数称为似然：

$$L(\theta)=\prod_{i=1}^{n}p(x_i\mid\theta)$$

最大似然估计选择使 $L(\theta)$ 最大的参数。为避免连乘下溢并简化求导，通常最大化对数似然。

## 抛硬币例子

若正面出现 $h$ 次、反面出现 $t$ 次，正面概率为 $p$，则：

$$\log L(p)=h\log p+t\log(1-p)$$

令导数为零，得到 $\hat p=h/(h+t)$：观察频率就是最大似然估计。

## 机器学习连接

最小化交叉熵等价于最大化分类数据的对数似然；高斯噪声假设下，最小二乘等价于最大似然。因此“损失函数”通常隐含着对数据生成方式的假设。

## 练习

若连续抛出 3 次正面，最大似然估计是 1。解释为什么这不表示真实硬币必然两面都是正面，并查阅贝叶斯先验如何缓解极端估计。
