# 蒙特卡洛与重要性采样：随机样本如何估计积分

## 学习目标

读完后，你能将期望写成随机样本均值；推导蒙特卡洛估计的无偏性和 $1/\sqrt{N}$ 误差；实现可复现的积分估计；并识别重要性采样中权重退化、支撑集不覆盖和有限样本偏差等边界。

## 从高维积分的困境开始

一维积分可细分网格，但 $d$ 维每轴取 $k$ 个点就要 $k^d$ 次评估，维度灾难很快出现。蒙特卡洛改为从分布采样：误差主要随样本数 $N$ 的平方根下降，理论上不直接随维度指数恶化。但这不是免费午餐：高维中选错采样分布会让方差巨大。

## 从期望到样本均值

若 $X\sim p$，目标是

$$\mu=E_p[f(X)]=\int f(x)p(x)\,dx.$$

独立同分布样本 $X_1,\ldots,X_N$ 给出

$$\hat\mu_N=\frac1N\sum_{i=1}^Nf(X_i).$$

线性性给出 $E[\hat\mu_N]=\mu$，独立性给出 $\operatorname{Var}(\hat\mu_N)=\operatorname{Var}(f(X))/N$。大数定律说明它收敛；中心极限定理在适当条件下给出近似正态误差。因此标准误差约为样本标准差除以 $\sqrt N$：要把误差减半，通常需四倍样本，不是两倍。

## 可运行实验：用随机点估计圆周率

在正方形 $[-1,1]^2$ 均匀取点，落入单位圆的概率为 $\pi/4$：

```python
from random import Random

def estimate_pi(samples, seed=0):
    if samples <= 0:
        raise ValueError("samples 必须为正")
    rng, inside = Random(seed), 0
    for _ in range(samples):
        x, y = rng.uniform(-1, 1), rng.uniform(-1, 1)
        inside += x * x + y * y <= 1
    return 4 * inside / samples

print(estimate_pi(100_000, seed=2026))
```

固定种子使教程测试可复现；评估真实随机算法时，应报告多个种子、均值、标准差和样本数，而不是只展示最接近真值的一次。

## 重要性采样：从更有用的地方取样

若能从提议分布 $q$ 采样，且目标分布的正密度区域都满足 $q(x)>0$，则

$$\mu=\int f(x)\frac{p(x)}{q(x)}q(x)\,dx=E_q[f(X)w(X)],\quad w(x)=p(x)/q(x).$$

于是用 $f(X_i)w(X_i)$ 的均值估计。理想 $q$ 会更多覆盖 $|f(x)|p(x)$ 大的区域，降低方差。未知归一化常数时常用自归一化估计

$$\tilde\mu=\frac{\sum_iw_i f(X_i)}{\sum_iw_i},$$

它有限样本一般有偏，但常一致；不能把它的便利误说成无偏。

## 权重诊断与算法边界

有效样本量常用近似

$$ESS=\frac{(\sum_iw_i)^2}{\sum_iw_i^2}.$$

若少数权重几乎承担全部和，ESS 远小于 $N$，表明“抽了很多样本”实则只有少数有效。此时增样本可能无效，应改进 $q$、分层/混合提议、截断权重或使用序贯蒙特卡洛。

```text
从 q 生成 N 个样本
计算 log_weight = log p(x) - log q(x)  （尽量在对数域）
用 log-sum-exp 稳定地归一化权重
计算估计值、ESS、最大权重占比和重复种子结果
若 ESS 太低：停止解释结果，重新设计提议分布
```

## 失败案例与工程边界

- **支撑集缺失**：若 $p(x)f(x)$ 非零而 $q(x)=0$，权重无定义，估计不可修复。
- **厚尾权重**：理论方差甚至可能不存在，置信区间和 CLT 近似会误导。
- **对数下溢**：高维密度连乘很快变为零，必须累计对数权重并用稳定归一化。
- **伪随机可重复不等于独立真随机**：种子用于复现；安全或物理模拟另有随机源要求。

## 常见误区

1. “蒙特卡洛的误差是 $1/N$。”错误：标准误差通常是 $1/\sqrt N$。
2. “高维下蒙特卡洛自动好。”错误：维度不显式进入收敛阶，但方差和权重退化常随维度恶化。
3. “权重归一化后一定更准确。”错误：它解决未知常数，不保证低方差且引入有限样本偏差。
4. “一次接近真值的运行就是验证。”错误：需重复运行并报告不确定性。

## 练习

1. **基础题**：由独立性推导样本均值方差为 $\sigma^2/N$。
2. **推导题**：从 $E_p[f]$ 插入 $q(x)/q(x)$ 推导重要性采样公式，并写出支撑集条件。
3. **编码题**：多运行 `estimate_pi`，验证样本数从 $N$ 增至 $4N$ 时标准差约减半。
4. **开放题**：为罕见故障概率估计设计 $q$，说明你会监控哪些权重诊断与如何报告不确定性。

## 练习答案提示

1. 独立样本均值的方差为 $\operatorname{Var}(X)/N$，标准差开平方后为 $\sigma/\sqrt N$；不要把方差和标准误混为一谈。
2. 将 $E_p[f]=\int f(x)p(x)dx$ 乘除 $q(x)$，得到 $E_q[f(X)p(X)/q(X)]$；要求所有 $p(x)f(x)\ne0$ 的位置都有 $q(x)>0$。
3. 多个独立种子下估标准差而非只看一次误差；$4N$ 的理论比例是约一半，有限重复会有随机偏离。
4. 令 $q$ 向故障区域倾斜但不能漏掉支撑集；报告 ESS、最大/尾部权重、重复运行、置信区间与提议分布参数，ESS 低时不应过度解释点估计。

## 延伸
