# 概率论深度版路线

## 主线

概率论深度版围绕一个问题展开：模型输出的概率意味着什么，又该如何从有限数据估计和检验它？每篇文章使用问题、定义、推导、代码、边界和四层练习组成闭环。

## 分层与顺序

| 层级 | 文章或主题 | 状态 |
| --- | --- | --- |
| 0 | 集合、事件、计数、条件化 | 计划补齐 |
| 1 | 条件概率、随机变量、期望、方差、协方差与分布 | [贝叶斯更新](/probability-ml/bayes)、[协方差与相关性](/probability-ml/covariance-correlation) 已深化 |
| 2 | 全概率、MLE/MAP、交叉熵、假设检验 | 最大似然与假设检验已深化 |
| 3 | 校准、蒙特卡洛、重要性采样、生成模型 | 蒙特卡洛与重要性采样已深化；其余由项目与后续文章补齐 |

## 项目连接

已提供[词袋朴素贝叶斯垃圾邮件分类器](/projects/naive-bayes-spam)：训练时以拉普拉斯平滑估计似然，预测时在对数域相加，并以混淆矩阵审查结果。下一步加入精确率、召回率与可靠性曲线，验证“后验高”与“模型校准良好”并非同一件事。

## 练习

1. 写出一个低基率事件，并比较敏感度与后验。
2. 说明 MLE 与 MAP 在小样本、强先验时为何会不同。
3. 实现二项模型的拉普拉斯平滑并比较零计数行为。
4. 为一个分类器设计校准测试，而不只测试准确率。
