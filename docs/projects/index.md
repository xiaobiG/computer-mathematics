# 综合项目

## 线性代数实验室

[线性代数实验室](/projects/linear-algebra-lab)将矩阵乘法、部分选主元消元和投影收进同一个可测试模块，是《程序员的线性代数》v0.2 的结课项目。

每个项目都应从一个明确问题出发，留下实验数据、推导说明和可复现代码。以下是按学习阶段安排的项目路线。

## 第一阶段：算法可视化实验室

用交互式页面或命令行日志展示二分查找、BFS、DFS 和排序过程。重点不是动画本身，而是把循环不变量、状态变化与复杂度对应起来。

**涉及**：离散数学、复杂度分析。

已提供可运行的 [实践指南](/projects/algorithm-lab)，从 BFS 队列轨迹观察最短路不变量。

## 第二阶段：文本相似度检索

将一组文档映射为词频向量，使用点积和余弦相似度给查询排序。再比较未归一化点积与余弦相似度的结果。

**涉及**：线性代数、基础统计。

已提供可运行的 [实践指南](/projects/text-similarity)，配套 Python 实现与单元测试。

## 第三阶段：浮点数错误博物馆

收集余额累计、相等比较、消去误差等可复现案例；每个案例给出错误输出、产生原因和修复方式。

**涉及**：数值计算、测试策略。

已提供可运行的 [实践指南](/projects/floating-point-museum)，配套可复现案例与单元测试。

## 第四阶段：密码学玩具箱

实现快速幂、模逆元和教学版 RSA 流程，并明确标记其仅用于学习，不可用于真实安全场景。

**涉及**：数论、算法复杂度、安全工程。

已提供可运行的 [实践指南](/projects/crypto-toybox)，配套小参数 RSA 与完整测试；仅用于学习。

## 项目提交清单

- 问题和输入输出的定义
- 前置数学概念链接
- 可运行代码与最小测试
- 复杂度或误差分析
- 失败案例与工程边界
