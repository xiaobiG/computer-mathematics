# 学习路线

这不是严格线性的课程。五个专题可独立阅读，但推荐按下列顺序建立基础。

## 第一阶段：构建计算思维

1. 离散数学：逻辑、集合、证明、复杂度、图论。
2. 线性代数：向量、矩阵、线性方程与投影。

## 第二阶段：理解不确定性与近似

3. 概率论：随机变量、分布、统计推断。
4. 数值计算：浮点表示、误差、稳定算法。

## 第三阶段：走向应用

5. 密码学数论：模运算、公钥体系与安全边界。
6. 综合项目：推荐系统、算法可视化、浮点数实验室与密码学玩具箱。

## 建议节奏

每周完成一篇核心文章，每四周用一个小项目复盘。遇到不熟悉的符号时，可先读直觉和代码部分，第二遍再进入推导。
