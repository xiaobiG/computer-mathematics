# 算法可视化实验室

这是算法状态与验证器的最小教学实现：`binary_search_trace.py` 审计二分查找的候选区间不变量，`relations.py` 检查有限关系并构造等价类划分，`complexity_counts.py` 计量线性/二次/指数增长和双指针比较数，`recurrence_trace.py` 审计二分缩减和归并树的逐层线性工作，`weighted_activity.py` 用穷举 oracle 验证加权活动选择 DP，并重放每个前缀 DAG 的选/不选转移，`bfs_trace.py` 记录无权最短路的队列分层，并用父路径、层级不等式和事件重放审计距离，`dijkstra_trace.py` 记录带权图的确定节点与松弛，`bellman_ford_trace.py` 将每轮松弛绑定到“至多 k 条边”不变量并拒绝可达负环，`dfs_trace.py` 记录发现/完成时间，`strongly_connected.py` 将互相可达顶点分组，`topological_trace.py` 记录 Kahn 拓扑排序如何解除依赖，并可重放检查拓扑序或残余正入度环证书，`sat_verifier.py` 对照 3-SAT 候选解的线性验证与指数枚举搜索，`floyd_warshall.py` 演示全源最短路与负环检测，`max_flow.py` 记录增广路径和最终最小割证书。站点中的《项目：算法可视化实验室》提供运行方法和实验问题。
